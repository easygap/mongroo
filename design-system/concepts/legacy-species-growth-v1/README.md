# 초기 종 성장 원화 v1 — 가시니·해바라기

가시니(`cactus`)와 해바라기(`sunflower`)는 `plant_species`에 처음부터 있었고
상점에 100씨앗으로 올라가 있는데, 성장 원화가 **한 장도 없었다.** 사면 씨앗부터
만개까지 다섯 단계 내내 대체 그림을 봤다. 그 다섯 단계를 채운 기록이다.

세렌·백화(`character-redesign-v6`)와 달리 만개조차 없어서 다섯 장을 전부 받았다.

## 어떤 캐릭터인가

둘 다 **끝까지 화분에 든 식물 캐릭터**다. 사람이 되지 않는다. 서버의 대화
페르소나가 이미 그렇게 잡혀 있다 — 가시니는 `가시 사이로 눈을 빼꼼`,
`모래를 톡 털고`, 해바라기는 `꽃 고개가 네 쪽으로 돌아왔어`, `큰 잎을 살짝
모으고`다. 사람형으로 만들면 대사와 어긋난다.

- **가시니**: 무뚝뚝하지만 속정 깊다. 둥근 세이지그린 몸통, 부드러운 가시 점,
  머리 위 붉은 꽃. 반쯤 감은 눈과 일자 입이 가지 단계부터 자리 잡는다.
- **해바라기**: 밝고 씩씩하다. 둥근 초록 몸통, 잎 귀, 머리 위 노란 꽃.
  **얼굴은 초록 몸통에 있고 꽃은 머리에 쓴 모자다** — 갈색 씨앗 원반에 얼굴을
  넣으면 징그럽게 읽힌다.

## 만들면서 버린 것

세 판을 버렸다. 다음 사람이 같은 데서 돌지 않게 적어 둔다.

1. **화풍을 글로만 설명했다.** `clean flat cel shading`, `crisp even ink
   outline`, `broad contiguous color shapes`, `limited palette`를 썼더니 굵은
   검은 선에 완전 평면인 벡터 스티커가 나왔다. 로스터는 얇은 갈색 선에
   부드러운 그러데이션과 볼터치다. **로스터 원화를 입력 이미지로 넣어야
   한다.** 뽀또(`baby-pot-25d-sprout-mosaic.webp`)가 기준이다.
2. **`포켓몬처럼 귀엽게`를 형태 지시로 읽었다.** 모루를 참조로 넣고 네발
   짐승으로 만들었더니 선인장 정체성이 사라지고 공룡이 됐다. 그 말은 귀여움에
   대한 것이었다. 화분 형태는 처음부터 맞았고 화풍만 문제였다.
3. **화분이 캐릭터를 압도했다.** 화분이 그림의 8할이면 주인공이 화분이 된다.
   화분은 전체 높이의 3분의 1을 넘지 않는다.

## 규격

- 낱장 다섯 장. `alpha/{slug}-{seed|sprout|branching|bloom|full-bloom}.png`
- 크로마 원본은 균일한 `#00FF00`, `sources/{slug}-{phase}-chroma.png`.
  제거는 `design-system/scripts/extract_green_sprite.py`가 한다.
- **키는 맞추지 않는다.** 각 파일에서 캐릭터가 캔버스를 채우게 그리면 된다.
  빌드가 512×768 캔버스에 목표 높이로 앉힌다.
- 감정 여섯 결은 만들지 않는다. 빌드가 중립본에서 파생한다.

## 키 곡선

사람형 계보(0.23·0.66·0.87·0.975)를 그대로 쓰면 **새싹이 개화보다 커 보인다.**
개화·만개는 잎과 곁가지가 폭을 먼저 채워서 목표 높이까지 크지 못하기 때문이다.
폭에 걸리는 칸까지 감안해 실측으로 잡았다.

| 단계 | 목표 | 가시니 실제 | 해바라기 실제 |
|---|---:|---:|---:|
| 씨앗 | 300 | 300 | 300 |
| 새싹 | 380 | 380 | 380 |
| 가지 | 460 | 460 | 437 |
| 개화 | 530 | 530 | 476 |
| 만개 | 620 | 620 | 554 |

해바라기는 잎이 벌어져 세 칸이 폭 한계(468)에 걸린다. 목표엔 못 미치지만
단조 증가라 성장은 읽힌다. 빌드가 순서를 검사해서 뒤집히면 멈춘다.

## 빌드

numpy가 필요해 `design-system/requirements.txt` 환경에서 실행한다.

```
python design-system/scripts/build_legacy_species_growth.py
```

종당 29개(중립 5단계 + 감정 6결×4단계)와 검수 시트를 `qa/`에 남기고, 원본과
산출물 해시를 `qa/legacy-species-growth.json`에 적는다. 점묘 관문이 먼저 도는데
승인 원화 실측(고주파 0.036~0.050)에 맞춰 0.075/0.0010으로 잡혀 있다. 이번
원화 열 장은 0.012~0.024로 여유 있게 통과했다.
