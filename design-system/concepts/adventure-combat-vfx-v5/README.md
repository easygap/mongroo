# 잉크 안개 VFX v5

상태: **production candidate — 실기 프로파일·최종 아트 승인 전**

엉킨 장부 뭉치의 두 번째 예고 `잉크 안개`를 오른쪽에서 왼쪽으로 흐르는
7프레임 채널링 공격으로 제작했다. 반투명 연무는 작은 화면에서 형태가 뭉개지고
크로마 경계도 불안정해져, 장부 먹물이 굵은 리본과 번짐 매듭으로 움직이는 방향으로
해석했다. 광역 공격은 접촉 뒤 세로로 크게 퍼지는 05번 프레임에서 읽힌다.

## 프레임 구성

| 프레임 | 구간 | 시간 | 역할 |
|---:|---|---:|---|
| 00 | anticipation | 170ms | 오른쪽에서 먹빛 리본을 둥근 매듭으로 압축한다. |
| 01 | release | 100ms | 매듭이 풀리며 왼쪽으로 긴 붓 결을 뻗는다. |
| 02 | travel | 65ms | 세 가닥을 작은 투사체로 묶어 이동한다. |
| 03 | travel | 65ms | 접촉 직전 앞부분을 안쪽으로 조인다. |
| 04 | contact | 80ms | 보이지 않는 접촉면에서 세로 부채꼴로 눌린다. |
| 05 | reaction | 120ms | 전열 전체를 덮는 먹빛 꽃 모양으로 확산한다. |
| 06 | recovery | 160ms | 끊어진 고리와 물방울이 오른쪽으로 회수된다. |

합계 760ms로 서버 `channel` 일반 모션의 6구간 시간과 정확히 같다. `travel`만
두 장으로 나눠 65ms씩 사용한다.

## 생성·알파 기록

- 모드: Imagegen 새 이미지 1회 + 직전 포즈를 참조한 연속 편집 6회
- 공통 프롬프트: 불투명한 청흑·남색·청록 수채 먹 리본, 옅은 하늘색 붓 결,
  한국형 포근한 동화책 게임 VFX, 오른쪽→왼쪽 진행, 캐릭터·배경·UI·문자·그림자
  제외, 단색 자홍색 `#FF00FF` 배경
- 포즈 지시: 압축 매듭 → 왼쪽 방출 → 세 가닥 비행 → 접촉 전 압축 → 세로 접촉
  부채 → 광역 충격 꽃 → 작은 회수 고리 순서로 위치와 실루엣만 변경
- 알파: Imagegen skill의 `remove_chroma_key.py`를 전 프레임에 동일하게 사용했다.
  border 자동 키, soft matte, despill, 1px contract, 0.5px feather 조건이며 하드 키로
  교체한 프레임은 없다.
- 원본: `sources/ink-mist/pose-*-chroma.png`
- 알파 마스터: `alpha/ink-mist/pose-*.png`
- 런타임: `app/assets/adventure/effects/ink-mist-v1/frame-*.webp`
- QA: `qa/ink-mist-v1-light-dark.webp`, `qa/ink-mist-v1-preview.webp`

런타임은 원화 색을 그대로 표시하고, 결 색상은 `srcIn`으로 만든 낮은 불투명도
블러 레이어에만 섞는다. 따라서 청록 붓 결을 잃지 않으면서 `mosaic` 결의 접촉
광만 전투 배경 위에 자연스럽게 남는다.

`production_ready`는 실제 기기 1×/2× 재생, 밝은·어두운 전투 배경, 저사양 GPU
디코드·블렌딩 프로파일을 통과한 뒤에만 `true`로 올린다.
