# 종잇장 회오리 VFX v4

상태: **production candidate — 실기 프로파일·최종 아트 승인 전**

엉킨 장부 뭉치의 `종잇장 회오리`를 오른쪽에서 왼쪽으로 재생하는 7프레임
공격 시퀀스로 제작했다. 코드가 공격 본체를 그리지 않도록 화면에 보이는 각
포즈를 Imagegen 원본 한 장으로 만들고, Imagegen 스킬의 크로마 제거 도구로
알파 마스터를 분리한 뒤 런타임 캔버스만 정규화한다.

## 프레임 구성

| 프레임 | 구간 | 시간 | 역할 |
|---:|---|---:|---|
| 00 | anticipation | 100ms | 오른쪽에서 장부 낱장을 압축한다. |
| 01 | release | 85ms | 종이가 왼쪽으로 펼쳐진다. |
| 02 | travel | 75ms | 회오리가 전장을 가로지르기 시작한다. |
| 03 | travel | 75ms | 왼쪽 접촉점 직전까지 이동한다. |
| 04 | contact | 90ms | 종이 끝이 접촉면에서 휘어진다. |
| 05 | reaction | 115ms | 물리적인 종이 부채꼴로 충격을 읽힌다. |
| 06 | recovery | 140ms | 종이가 접히며 오른쪽으로 회수된다. |

## 생성 기록

- 모드: 새 이미지 1장 생성 후 직전 포즈를 참조한 연속 편집 6회
- 배경: 자홍색 크로마(`#FF00FF` 지시, 모델 출력의 미세 편차는 border 자동 샘플링)
- 알파: 00·01·02·04는 경계 자동 샘플링 + 소프트 매트·디스필, 03·05·06은
  자홍색과 가까운 청록·갈색 디테일을 보존하기 위해 경계 자동 샘플링 + 하드 키를
  적용했다. 두 방식 모두 밝은/어두운 배경 QA에서 외곽선을 확인했다.
- 런타임: `app/assets/adventure/effects/paper-flurry-v1/`
- QA: `qa/paper-flurry-v1-light-dark.webp`, `qa/paper-flurry-v1-preview.webp`

생성 프롬프트의 공통 불변 조건은 오래된 크림색 장부 종이, 따뜻한 갈색 윤곽,
이끼 얼룩, 절제된 청록 먹빛, 캐릭터·배경·UI·문자·그림자 제외다. 프레임마다
준비·방출·이동·접촉·충돌·회수만 바꾸고 재질과 방향은 유지했다.

`production_ready`는 실제 기기에서 1×/2× 재생, 밝은/어두운 전투 배경,
저사양 GPU의 디코드·블렌딩 프로파일을 통과한 뒤에만 `true`로 올린다.
