# 탐험 입구: 시각 지도 개편

기준일: 2026-09-16. 기존 진입 화면은 입구 그림 아래에 설명과 버튼, 잠긴 모드 목록을 배치했다. 장소 사이의 관계와 대원의 위치를 보여 주지 못했다. 이번 변경의 기준은 **화면을 열었을 때 탐험 세계가 먼저 보이고, 실제 장소를 눌러 행동을 고르는 것**이다.

## 설계

- 색: 지도 잎색 `#63856E`, 물색 `#559B9D`, 조작부 잉크색 `#173E38`, 종이색 `#F3F4E9`, 현재 목적지 `#F5DC80`. 다른 지역은 같은 명도 대비를 유지하며 관측실의 목재, 씨앗고의 황혼으로 구분한다.
- 글꼴: 기존 Gothic A1. 지역·목적지만 제목 크기로 표시하고, 설명은 장소 상세에서 읽는다. 그림에 글자를 생성하지 않는다.
- 배치: 세로 지도 전체가 탐험 입구다. 위에는 지역 선택과 수첩, 아래에는 다음 목적지와 출발/편성 조작을 둔다. 대화면은 지도 옆에 탐험대를 배치한다.
- 지도에는 8곳의 실제 장소를 배치한다. 목적지 표식, 완료 표시, 잠금 표시, 선택한 대원은 Flutter 위젯으로 그린다. 완료 수와 해금은 서버 상태를 따른다.
- 장소를 누르면 정보 시트가 열린다. 잠긴 곳은 조건을 확인할 수 있고, 열린 곳은 편성으로 이어진다. 이미 사용한 탐험대는 아래 출발 버튼으로 바로 다음 탐험을 시작한다.
- 캐릭터의 정지 자세 애니메이션을 유지한다. 추가적인 반짝임, 자동 카드 등장, 무관한 카운트다운은 사용하지 않는다. 동작 줄이기 설정을 따른다.
- 순찰과 수첩은 별도 경로로 열려 닫으면 지도에 돌아온다. 탐험 탭 자체가 마지막에 열어 둔 텍스트 목록으로 남는 문제를 없앤다.
- 지도 위 수첩 버튼은 조사한 장소의 이미지와 이야기만 담은 현장 수첩을 연다. 순찰의 주간 진행률과 소지품 목록은 이 화면에 섞지 않는다.

## 검증

- 지도 진입, 8개 장소, 대원 표시, 장소 선택→편성, 잠금 유지, 지역 이동, 깊은 조사, 기존 해금 조건, 첫 출발/재출발을 확인하는 위젯 검사.
- 320 / 390 / 1280px 및 200% 글자 크기에서 레이아웃과 48dp 조작 영역 검사.
- Flutter 전체 검사 533개 통과. 귀환 동선과 현장 수첩을 정리한 뒤 관련 검사 36개를 다시 실행해 통과했다. `flutter analyze --no-pub`도 문제 없음.
- `flutter build web --no-pub --no-web-resources-cdn --no-wasm-dry-run --output=build/review-web` 성공. 로컬 API를 연결한 최종 미리보기는 `http://127.0.0.1:8100/#/explore`에서 제공한다.
- 브라우저 390×844 및 1280×900에서 지도, 실제 장소 터치→편성→출발, 진행 중 지도 복귀→이어하기, 귀환→기본 지도 복귀를 확인했다. 순찰을 열고 닫아도 지도로 돌아온다.
- 최종 현장 수첩에서 완료한 두 장소의 이미지와 기록, 펼친 이야기의 실제 캡션, 지도로 돌아가기를 확인했다. 최종 브라우저 콘솔에 오류 없음. 테스트용 화면 크기 설정은 해제했다.
- 화면 너비를 바꾼 뒤 Flutter Web의 접근성 스크롤 좌표가 남아 다른 장소를 선택하던 문제를 발견했다. 크기/지역 변경 때 해당 스크롤 입력 영역을 새로 만들도록 수정한 뒤, 모바일→대화면→모바일 양방향에서 같은 장소가 열리는 것을 확인했다.
- 실제 전투·이동은 기존 필드의 서버 판정으로 이어진다. 새 지도 그림 자체를 자유 이동 필드라고 표현하지 않는다.
