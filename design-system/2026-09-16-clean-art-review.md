# 2026-09-16 — 질감과 게임 화면 재검수

원화 v2의 단순화와 반복 배치는 사용자에게 다시 지적받았다. 원화와 질감의 현행 기준은 [탐험 공간 재설계](2026-09-16-environment-review.md)이며, 아래는 중간 수정 이력이다. 캐릭터 연결·전투 판정·접근성 수정은 유지한다.

## 이번 수정의 이유

v1 지도는 장소마다 돌·잎·꽃·반사광을 높은 밀도로 채웠다. 휴대폰 크기에서 지형과 작은 점무늬가 경쟁하고, 캐릭터와 UI는 서로 다른 화풍으로 보였다. '픽셀 아트'라는 프롬프트만으로 결과를 분류한 것이 잘못이었다. 이 문서는 이전 visual-exploration 문서의 원화·질감 규칙을 대체한다.

## 디자인 판단

- 큰 색면, 단순한 재료, 분명한 외곽선을 사용한다. 풀밭은 풀잎의 집합이 아닌 하나의 바닥 면이다.
- 기본색은 잎 #80AC79, 풀밭 #D8E5CB, 모래길 #F2D8A4, 물 #82BECA, 먹색 #173E38, UI 바탕 #FAFCF5. 지역마다 수면·유리·관측 도구의 형태와 바닥색을 바꾼다.
- Gothic A1을 유지한다. 장소명은 titleMedium, 상태는 labelSmall. 수사적인 제목·태그라인을 추가하지 않는다.
- 모바일은 [지역/수첩] → [직접 누르는 그림 지도와 대원] → [선택한 장소/편성/탐험하기] → [기존 탐색 탭] 순서다. 장소명과 설명은 왼쪽 정렬, 주행동은 엄지 영역에 둔다.
- 흔한 숲 콘셉트 그림으로 끝나지 않도록 압화 보관대·서랍장·종·망원경·씨앗병을 실제 스테이지에 대응시킨다. 화면 전체에 동일한 장식 밀도를 주지 않는다.
- 길 위의 점선, 지도 상단 암막, 핀의 하드 그림자를 제거한다. 완료/잠김 상태는 작은 표식으로 구분한다.

## 동작 변경

장소를 누르면 그림 지도 위에서 선택 상태와 아래 메뉴만 바뀐다. 자세한 문장은 '살펴보기'로 열고, 다른 장소를 선택하면 그 장소의 편성으로 출발한다. 진행 중인 탐험이 있으면 다른 장소의 출발을 막는다. 서버의 해금·보상·선택 판정은 유지한다.

걷기 화면은 바깥 카드와 별도 설명 줄들을 줄이고 필드를 확장했다. 현재 장소 머리글을 누르면 기존 경로 오버레이를 열 수 있으며, 닫으면 카메라와 위치를 유지한다. 지형은 단색 면과 충돌 경계로 직접 그린다. 지도·걷기·전투·사건에서 실제 선택된 식물의 성장 단계·품종·착용 정보를 같은 PlantView로 전달한다. 품종 스프라이트가 없을 때 다른 인간 캐릭터로 바뀌던 폴백을 제거했다.

첫 장소가 하단 출발 메뉴에 가려지지 않도록 지도 스크롤에 위아래 공간을 둔다. 장소의 좌표는 원화 속 사물에 맞추고, 현장 수첩의 작은 그림도 해당 사물 중심으로 잘라 보여 준다.

앱과 로딩 화면의 m 심볼은 두 색의 벡터로 단순화했다. 플랫폼 설치 아이콘은 유지한다. 한국어 제목·전투 HUD·로그인 화면은 Gothic A1로 맞추고 글자 그림자와 패널의 픽셀 입체 테두리를 없앴다. 전투의 작은 기술 그림은 명확한 동작 아이콘으로 교체했다.

실제 전투 검수에서 기존 품종 코드 `basic_sprout`·`mood_seed`가 안내 NPC의 기술로 떨어지는 문제를 발견했다. 저장된 품종은 유지하면서 전투 판정에서 `baby-pot`으로 해석한다. 새싹은 새싹 응원·뿌리 포옹을 사용하고, 기본 동작은 '기본 공격'으로 표기한다.

## 적용한 이미지

내장 imagegen 도구의 generate/edit 모드를 사용했다. CLI/API 키 경로는 사용하지 않았다. v1 파일은 비교용으로 보존하고 런타임 참조는 아래 v2로 교체했다.

- `app/assets/adventure/echo-well-atlas-v2.png`
- `app/assets/adventure/heartwood-atlas-v2.png`
- `app/assets/adventure/starlight-atlas-v2.png`
- `app/assets/adventure/moss-encounter-v2.png`
- `app/assets/adventure/echo-encounter-v2.png`
- `app/assets/adventure/heartwood-encounter-v2.png`

각 파일의 프롬프트는 이 폴더의 동명 `.prompt.txt` 파일에 있다. 새 캐릭터 시안은 PNG에 실제 알파가 없고 격자가 그려져 있어 사용하지 않았다. 원래의 투명 식물 원화를 사용한다. 기존 모든 수집 캐릭터와 의상 원화를 재제작한 것은 아니다.
