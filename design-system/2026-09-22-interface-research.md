## 채택한 방향

공통 UI는 흰색과 차콜을 중심으로 한다. 큰 유색 카드, 파스텔 배지, 장식 격자는 사용하지 않는다. 캐릭터와 지역 원화가 화면의 색을 맡고, 붉은색은 피해와 오류처럼 뜻이 있는 곳에 쓴다. 앞서 시도한 베이지·초록과 코발트·오렌지 조합은 채택하지 않았다.

| 역할 | 밝은 화면 | 어두운 화면 |
| --- | --- | --- |
| 바탕 | `#F7F7F7` | `#121212` |
| 읽기 면 | `#FFFFFF` | `#1B1B1B` |
| 본문 | `#202020` | `#FFFFFF` |
| 보조 문구 | `#616161` | `#BDBDBD` |
| 주요 행동 | `#242424` | `#F0F0F0` |
| 선택 면 | `#EFEFEF` | `#343434` |
| 경계선 | `#DEDEDE` | `#404040` |
| 오류·피해 | `#BE233C` | `#FF9BAC` |

전투는 원화 위에서 읽기 쉬운 어두운 조작부를 쓴다. 지도용 저해상도 도트를 크게 늘리던 적은 준비된 고해상도 대기·공격·피격 원화로 연결한다. 해당 원화가 없는 보스는 자신의 기존 그림을 유지한다.

## 글꼴과 문구

Wanted Sans Regular·Medium·SemiBold·Bold·ExtraBold를 수정 없이 번들에 넣었다. 제작자 표기와 OFL은 `app/assets/fonts/README-WantedSans.md`에 있다. 메뉴·안내·버튼은 본문 글꼴을 쓰며 피해 숫자 같은 제한된 게임 연출에만 별도 글꼴을 허용한다.

| 이전 표현 | 현재 표현 |
| --- | --- |
| 마음빛 읽기 | 오늘의 기분 |
| 오늘의 다음 한 칸 | 오늘 할 일 |
| 오늘의 온실 루트 완료 | 오늘 할 일을 마쳤어요 |
| 성장결 / 모아결 | 성장 타입 / 무지개 |
| 자동 지휘 | 자동 전투 |
| 공유 집중력 | 팀 기력 |
| 마음 지키기 | 방어 |
| Lv.23 해금 | 23레벨부터 사용 |
| 현장 기록: 되울림 | 메아리 기록 |
| 잠시 여운 남기기 | 닫기 |

숫자·비용·제약은 문구를 줄이면서 빼지 않는다. 지역과 캐릭터의 고유 이름은 이야기에서 쓸 수 있지만, 다음 행동을 설명할 때는 일상적인 말을 우선한다. API 코드와 저장 형식은 바꾸지 않는다.

## 전투와 입력

- 스킬을 두 칸씩 배치하고 내용에 따라 행 높이를 결정한다. 긴 이름을 고정 높이에서 잘라내지 않는다.
- 상단에 턴·자동 전투·설정을 모은다. 200% 글씨에서는 상태를 별도 줄로 옮긴다.
- 적의 다음 공격 대상과 피해를 장면 위에 표시한다. 약점·내성·단계 규칙은 상대 정보에서 확인한다.
- 접촉 프레임에 피격 모션·효과음·피해 숫자·체력 변화를 맞춘다. 일반 타격 36ms, 강한 타격 58ms, 마지막 타격 76ms의 짧은 정지를 적용한다. 동작 줄이기에서는 정지를 생략한다.
- 지역 음악은 같은 마디 위치에서 240ms 동안 교차 전환한다. 마지막 전투·낮은 체력·보스 단계에 따라 강도를 조절한다.
- 현재 장면에 필요한 소리를 미리 준비한다. 음소거·백그라운드 전환 뒤에 지연된 소리가 재생되지 않게 한다.
- 설정·설명·선택 창이 열리면 자동 전투를 잠시 멈춘다. 연속 입력은 한 번만 제출한다.
- 키보드 1–6, 좌우 대원 선택, 우클릭 설명을 지원한다. 이동 스틱의 중앙 복귀, 두 번째 손가락, 포커스 이탈을 처리한다.
