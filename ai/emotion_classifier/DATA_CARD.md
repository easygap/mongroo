# 데이터 카드 — 감정 분류 학습 데이터

## 출처

- 데이터셋: AI Hub 감성 대화 말뭉치
- 버전: v1.2 (파이프라인 태그 `aihub-v1.2`)
- 제공처: 한국지능정보사회진흥원(NIA) AI Hub
- 링크: https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=86
- 내용: 감정 라벨이 달린 한국어 1:1 대화. 세부 감정 60종(E10~E69)이
  6개 대분류(기쁨/슬픔/분노/불안/상처/당황) 계열로 구성된다.

## 라이선스와 보관 원칙

- AI Hub 이용정책상 원본 데이터의 재배포가 금지된다. 원본과 원문이 포함된
  파생물은 저장소에 커밋하지 않는다.
- 원본은 저장소 밖 `AIHUB_DATA_ROOT`에 보관하고, 전처리 산출물(parquet)은
  `ai/data/processed/`에 두되 `.gitignore`로 커밋을 차단한다.
- 저장소에는 전처리·학습·평가 코드와 메타 정보(개수, 분포, 해시)만 남긴다.
- 이용 약관과 활용 범위는 AI Hub 데이터 이용정책 페이지에서 다운로드 시점에
  다시 확인한다: https://aihub.or.kr/intrcn/guid/usagepolicy.do

## 전처리와 split

- `prepare_data.py`가 원본 JSON(권장) 또는 xlsx에서 사람 발화, 감정 코드,
  화자 ID를 추출한다. 중복 텍스트와 5자 미만 텍스트는 제외한다.
- 라벨은 `label_mapping.py`의 코드 프리픽스 규칙으로 6대분류에 매핑한다.
  매핑 버전(`MAPPING_VERSION`)과 검증 여부가 meta.json에 기록된다.
- split은 문장 무작위 분할이 아니라 화자(profile-id) 단위
  GroupShuffleSplit(train 80 / val 10 / test 10, seed 42)이다. 같은 화자의
  발화가 서로 다른 split에 들어가는 누수를 막기 위함이다.
- 전처리 코드의 SHA-256, 원본 파일 해시(앞 16자), split별 클래스 분포가
  `meta.json`에 함께 저장된다.

## 알려진 한계

- 라벨 매핑이 원본 라벨표와 대조 완료되기 전까지는 잠정 매핑이다
  (README의 검증 절차 참고).
- 말뭉치는 조사자가 설계한 시나리오 기반 대화라서 실제 일기·자유 기록의
  문체 분포와 다르다. 모델 카드의 주장과 별개로 인도메인(일기 형태)
  평가셋을 따로 만들어 확인하기 전에는 일기 도메인 성능을 보장할 수 없다.
- 중립(감정 없음) 클래스가 없다. 중립 데이터 출처가 확정되기 전에는 중립
  클래스를 임의로 만들지 않고, 낮은 확신 예측은 uncertain으로 abstain한다.
- xlsx 배포본에는 화자 ID가 없어 행 단위 그룹으로 대체된다. group split의
  누수 방지 효과가 약해지므로 JSON 배포본 사용을 권장한다.
- 6대분류 간 경계가 모호한 표현(예: 상처와 슬픔)이 많아 라벨 노이즈가
  존재한다. per-class 지표와 confusion matrix로 확인한다.
- 이 데이터로 학습한 분류기는 일반 감정 분류용이며 위기 신호 탐지 용도의
  검증을 거치지 않았다. 안전 검사는 별도 레이어가 담당한다(docs/safety.md).
