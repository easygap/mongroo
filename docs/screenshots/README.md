# 화면 캡처

README에 쓰는 실제 웹 화면을 모아 둔다. 디자인 시안이나 생성 이미지는 넣지 않고, 개인 정보가 없는 QA 계정으로 실행 중인 화면만 촬영한다.

```text
docs/screenshots/web/
├─ 01-home-wide.webp
├─ 02-record-wide.webp
├─ 03-calendar-wide.webp
├─ 04-garden-wide.webp
├─ 05-shop-wide.webp
├─ 06-museum-detail-wide.webp
└─ 07-reports-wide.webp
```

웹 화면은 1440×960으로 맞추고 WebP로 저장한다. 같은 화면을 다시 찍을 때는 파일명을 유지해 README 링크가 바뀌지 않게 한다.

`mobile/`에는 모바일 화면 확인용 캡처를 따로 보관한다. 루트 README는 웹 화면을 기준으로 구성한다.
