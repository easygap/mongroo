# 화면과 GIF

프로젝트 소개에 사용하는 실제 게임 화면입니다. 개인 정보가 없는 테스트 계정으로 플레이하며 촬영했습니다.

## 현재 사용하는 자료

| 폴더 | 내용 |
| --- | --- |
| `release-2026-09-22/` | 홈, 일기, 기록 달력, 성장 도감, 탐험 지도, 전투, 설정, 방 꾸미기 |
| `rewards-2026-09-22/` | 퀘스트 보상·캐릭터 해금 GIF와 일기 보상·성장 확인 화면 |

기본 화면은 Flutter Web 릴리스 빌드에서 390×844 크기로 촬영했습니다. 성장 도감은 여섯 타입을 함께 볼 수 있도록 540×1320으로 촬영했습니다. GIF 두 편은 실제 화면 녹화를 360px 너비, 15fps로 변환한 것입니다.

[한국어 소개](../../README.md)와 [영어](../i18n/README.en.md)·[일본어](../i18n/README.ja.md)·[중국어](../i18n/README.zh-CN.md) 소개가 같은 파일을 사용합니다. 언어별로 이미지를 복제하지 않습니다.

## 다시 촬영할 때

- 테스트 계정을 사용하고 일기·이메일 등 개인 정보가 나오지 않는지 확인합니다.
- 앱과 테스트용 API를 연결해 촬영합니다. 실제 화면에 없는 버튼·수치·연출을 합성하지 않습니다.
- 창 크기를 바꾼 뒤 화면이 안정될 때까지 기다리고, 마우스를 치워 툴팁이 남지 않게 합니다.
- 보상이나 구매를 촬영할 때는 앱에서 실제 요청을 보내고 결과를 확인합니다.
- 이미지 파일을 바꾸면 네 언어 소개와 해당 이미지를 사용하는 검수 문서도 함께 확인합니다.

테스트용 SQLite 서버와 계정이 필요한 경우 [demo_up.py](tools/demo_up.py)를 사용할 수 있습니다. 이 도구는 `tmp/demo/`에 별도 데이터를 만들며, 다시 실행하면 그 테스트 데이터가 초기화됩니다.

현재 사용하지 않는 옛 UI 캡처, 콘셉트 표지, 이전 화면 좌표에 맞춰 둔 촬영·변환 스크립트는 정리했습니다. 지난 화면은 [이전 커밋](https://github.com/easygap/mongroo/tree/b0f4ce04041a9f79b7ac6928247aef1925089809/docs/screenshots)에서 볼 수 있습니다.
