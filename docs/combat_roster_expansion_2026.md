# 전투 로스터·성장·보스 연출 v7 구현 명세

> 이 문서는 2026-08-11의 12종 로스터 구현 기록이다. 15종·고유 스킬 30종·전용
> 에셋 완성 이후의 현행 기준은 [탐험 전투·캐릭터 성장 시스템 v8](combat_system_design_v8.md)을 따른다.

최종 갱신: 2026-08-11
대상 버전: `combat-kit-v7`, `battle-state-v3`, `0032_combat_roster`
상태: **판정·데이터·주요 UI 구현 완료 / 전용 공격 스프라이트 제작 진행**

이 문서는 캐릭터 성장부터 던전 전투까지 한 번에 확인하는 구현 기준이다. 수치 판정은
`server/app/content/expeditions/combat_identity.py`와 `combat.py`, 화면 계약은
`app/lib/features/expedition/domain/expedition_combat_models.dart`가 최종 원본이다.

## 1. 결론부터 정리

| 질문 | 현재 답 | 구현 증거 |
|---|---|---|
| 캐릭터마다 고유 스킬이 있는가 | 플레이 가능 12종 모두 고유 I·II 보유 | 고유 code 24개와 VFX family 24개 validator |
| 레벨마다 쓸 수 있는 스킬이 다른가 | Lv3·7·9·23에서 슬롯이 순차 해금됨 | 서버 `available`, `unlock_level`, 변조 요청 422 거절 |
| 고레벨이 단순 피해만 높은가 | T2/T3에서 회복·보호·집중·약화·소생·취약 기믹도 강화됨 | `effect_values`, `mechanic_summary` |
| 감정에 따라 고유기 색이 바뀌는가 | 6개 감정 팔레트를 고유 VFX 위에 얇게 합성함 | 이벤트의 두 색상과 Flutter blend layer |
| 고레벨 연출이 더 좋은가 | VFX 강도, SFX stem, 카메라, 고유 II 모션이 tier별로 확장됨 | `presentation_tier`, `audio_layer`, `camera_profile` |
| 던전 난이도가 상승하는가 | 스테이지 밴드·파티 성장 장벽 보정·라운드 제한이 함께 상승함 | 전투 시작 snapshot과 지역 콘텐츠 validator |
| 보스전이 별도 설계됐는가 | 기억서고 보스가 100%·66%·33% 3페이즈로 전환됨 | 상성·의도·위력·집중 보상·연출 이벤트 변경 |
| 간호사·버퍼가 실제 캐릭터인가 | 백화와 세렌이 상점, 품종, 성장, 전투, 도감에 연결됨 | DB migration과 구매 동시 품종 해금 |
| 신규 재화 복장이 있는가 | 구매 시 포함되는 전용 기본 복장 2종이 구현됨 | 도감 태그와 v4 캐릭터 원화 |

여기서 “고유 스킬 구현”은 이름만 다른 데이터가 아니라 서버 판정, 쿨타임, 계수,
모션 family, 감정색, UI 설명까지 연결됐다는 뜻이다. 다만 24개 공격 모두가 전용 프레임
스프라이트를 가진 것은 아니다. 미제작 family는 현재 결별 production fallback을 사용하며,
전용 sprite 완성 전에는 `production_ready`로 표시하지 않는다.

큰 기믹 변화로 체감시키고 화면을 덮는 장식은 제한한다.

### 4.1 지원·제어 기믹의 tier 변화

| 효과 | T1 | T2 | T3 |
|---|---|---|---|
| 일반 단일 회복 | 회복 1 | 회복 2 | 회복 2 + 보호 1 |
| 응급 개화 | 회복 2 | 회복 2 + 보호 1 | 회복 3 + 보호 2 |
| 백의정원 선서 | 단일 회복+전원 보호 | 전원 회복·보호 | 전원 회복 2+·보호 2+·1인 소생 |
| 황금 첫박 | 후속 위력 +10% | +15%, 집중 1 환급 | +22%+, 집중 1 환급 |

지원·제어 스탯이 높으면 `+` 구간이 추가로 커진다. 같은 라운드에서 세렌 다음에
행동한 대원만 증폭을 받으므로 편성뿐 아니라 행동 순서도 공략 요소가 된다.

## 5. 캐릭터 전투 스탯

기존 일기 기반 `care/focus/courage/insight`와 별도로 캐릭터 체질을 네 값으로 둔다.

- 공격: 기본·고유 raw 위력 보정
- 생존: 최대 HP와 마음 지키기 보호량 보정
- 지원: 회복·전원 보호·지휘 증폭 보정
- 제어: 적 위력 감소·취약 보정

```text
stat = base
     + round_half_up((level - 1) × growth_tenths / 10)
     + floor((rarity - 1) / 2)
     + emotion_bonus
```

감정 보너스는 햇살 `지원+2`, 빗물 `생존+1/제어+1`, 불씨 `공격+2`, 달빛
`제어+2`, 별빛 `공격+1/제어+1`, 모아 `생존+2`다. 감정은 역할을 뒤집지 않고
같은 캐릭터의 세부 운용만 바꾼다.

백화의 시작 체질은 `공격8/생존11/지원14/제어8`, 성장치는 레벨당
`0.3/0.4/0.5/0.3`이다. 세렌은 `9/8/11/14`, 성장치는
`0.3/0.3/0.4/0.5`다. 따라서 백화는 회복·생존, 세렌은 취약·의도 제어에서 가장
높은 상한을 가진다.

## 6. 희귀도와 피해 계산

| 희귀도 | Lv1 고유 계수 | Lv30 고유 계수 |
|---:|---:|---:|
| 1 | 100% | 120% |
| 2 | 101% | 124% |
| 3 | 102% | 128% |
| 4 | 103% | 133% |
| 5 | 104% | 139% |

비싼 캐릭터는 처음부터 근소하게 강하고 성장 상한도 높다. 차이를 무작정 raw 피해에
몰지 않고 백화의 소생, 세렌의 후속 증폭처럼 역할 기믹에 더 큰 가치를 배분한다.

피해는 아래 순서로만 계산한다.

```text
raw       = P + 관련 일기 능력치 + 공격 스탯 보정
growth    = round_bp(raw, rarity_scale_bp)
tiered    = round_bp(growth, T1 100% / T2 110% / T3 122%)
matched   = round_bp(tiered, 약점 150% / 중립 100% / 내성 60%)
effected  = round_bp(matched, 관통·간파·최후저항 배수)
ordered   = round_bp(effected, 지휘 증폭 × 적 취약)
final     = max(1, ordered)
```

프리즘 굴절 약점은 항상 맞출 수 있는 대신 130%다. 치명타·회피·숨은 명중률은 두지
않아 버튼을 누르기 전에 결과를 예측할 수 있게 한다.

## 8. 쿨타임·자원·행동 순서

- 라운드 `r`에 CD `N` 스킬 사용 시 `ready_round = r + N + 1`.
- 고유 I은 전 tier CD 1. 대표기를 매 라운드 무한 반복할 수 없다.
- 일반 고유 II는 `3/3/2`, 백화·세렌 고유 II는 `4/4/3`.
- 감정 선택 I은 CD 2, 스킬북 선택 II는 기본 CD 3.
- 쿨타임은 대원별이며 웨이브 전환 때 초기화하지 않는다.
- 집중이 부족하거나 쿨타임 중인 슬롯은 숨기지 않고 정확한 이유를 표시한다.
- 한 라운드의 첫 행동자가 적 `front` 의도의 대상이 된다.
- 세렌의 증폭과 취약은 스킬 자신이 아니라 뒤이어 행동한 대원에게 적용된다.

이 규칙으로 “누가 어떤 스킬을 쓰는가”뿐 아니라 “누가 먼저 움직이는가”도 공략이 된다.

## 9. 모션·VFX·SFX·카메라

모든 행동은 아래 여섯 구간을 가진다.

```text
anticipation → release → travel → contact → reaction → recovery
```

| tier | VFX | SFX | 카메라 | 고유 II |
|---|---|---|---|---|
| T1 | intensity 0.86, 원색 한 층 | light stem | steady | 기본 archetype |
| T2 | 1.00, trail·접촉 보강 | full stem | impact | ultimate timing 사용 |
| T3 | 1.14, 감정색 두 층 | signature + 약점 cue | impact/ultimate | 가장 긴 준비·접촉·회복 |

백화는 `triage-step`과 `white-oath`, 세렌은 `downbeat`와 `silent-coda` 전용 프로파일을
쓴다. 앱은 `audio_layer`에 따라 스킬 본체와 저음량 약점 cue를 겹친다. 접근성의
움직임 줄이기에서는 이동·흔들림을 제거하되 접촉 시점과 피해 정보는 유지한다.

전용 스킬 아이콘은 다음 네 경로에 연결했다.

## 10. 던전 상승과 보스 3페이즈

일반 스테이지는 지역 장벽 밴드, 적 의도 위력, 웨이브 수, 라운드 예산으로 난이도가
상승한다. 동시에 파티 성장지수로 장벽을 최대 1.30배 snapshot해 고레벨 파티가 모든
전투를 1라운드에 지우는 현상을 막는다. 낮은 성장 구간은 장벽 보정을 1.00으로 유지해
레벨이 올랐는데 오히려 손해 보는 초반 반올림 구간을 없앴다.

기억서고 보스는 다음 순서로 전환된다.

| 장벽 구간 | 페이즈 | 변경점 |
|---:|---|---|
| 100~67% | 색인 수호 | 기본 상성·의도 학습 |
| 66~34% | 뿌리 봉쇄 | 약점·내성·의도 cycle 변경, 적 위력 +1, 집중 보상 |
| 33~1% | 최종 말소 | 상성 재변경, 적 위력 +2, signature 연출·집중 보상 |

페이즈 전환은 피해 직후 서버에서 판정한다. `boss_phase` 이벤트가 먼저 재생되고 다음
적 행동은 이미 새 페이즈 패턴을 사용한다. 한 번의 큰 공격으로 두 경계를 넘으면 두
페이즈를 순서대로 모두 기록한다. 장벽이 0이면 페이즈 연출보다 승리를 우선한다.

## 11. 신규 프리미엄 캐릭터와 재화 복장

### 백의 수호사 백화 — 280 씨앗

- 성인 캐릭터, 밝은 21호 계열 피부, 긴 다크 와인 헤어, 고양이상 눈매.
- `순백 트리아주` 복장을 캐릭터 구매 시 기본 포함.
- 흰색·피치·코랄만 쓰고 큰 장신구·날개·반짝이 장식을 배제.
- 정원 모션 `nurse_breathe`, 전투 역할 `premium_healer`.
- T3 백의정원 선서가 쓰러진 동료 한 명을 1 HP로 일으킨 뒤 전원 회복·보호.

### 공명 지휘자 세렌 — 240 씨앗

- 성인 캐릭터, 밝은 피부, 딥 블루블랙 헤어, 고양이상 눈매.
- `미드나잇 레조넌스` 복장을 캐릭터 구매 시 기본 포함.
- 매트 플럼 드레스와 얇은 지휘봉만 남긴 미니멀 실루엣.
- 정원 모션 `maestro_cue`, 전투 역할 `resonance_director`.
- 황금 첫박은 후속 행동 증폭, 침묵의 코다는 적 위력 감소와 취약을 동시에 부여.

두 복장은 별도 wardrobe pose sheet가 아니라 v4 캐릭터 원화에 통합된 구매 포함 기본
재화 복장이다. 도감 상세에 복장명과 “구매 시 포함”을 표시해 실제 획득 범위를 명확히
한다. 향후 갈아입기용 36 pose sheet를 만들기 전까지 호환되지 않는 wardrobe 레이어를
지원한다고 표시하지 않는다.

## 12. 구매·성장 데이터 연결

`0032_combat_roster` 마이그레이션은 다음을 한 번에 처리한다.

1. 플레이 가능 12종을 `plant_species` 성장 계보로 등록한다.
2. 기존 10종 캐릭터 item에 `species_code`와 성장 asset namespace를 연결한다.
3. 백화·세렌 상점 item, 가격, 희귀도, 서사, 복장 메타데이터를 추가한다.
4. 기존 캐릭터 보유자는 대응 품종을 자동 해금한다.
5. 신규 구매는 item과 품종 해금을 같은 트랜잭션으로 처리한다.
6. 신규 가입자는 뽀또 item과 뽀또 품종을 함께 받는다.
7. 다운그레이드 시 실제 식물이 참조하는 성장 계보와 사용자 해금은 보존하고,
   참조되지 않은 신규 계보만 정리한다.

구매만 됐는데 성장 화면에서 캐릭터를 고를 수 없던 기존 구조를 이 단계에서 해소했다.

## 13. API 계약

kit이 추가로 보내는 필드:

```json
{
  "version": 7,
  "role": "premium_healer",
  "role_label": "백의 수호",
  "combat_stats": {"offense": 16, "vitality": 24, "support": 35, "control": 18},
  "combat_stat_labels": {"offense": "공격", "vitality": "생존", "support": "지원", "control": "제어"},
  "emotion_vfx_palette": {"primary": "#FFD48A", "secondary": "#FF8FA8"}
}
```

스킬과 전투 이벤트는 같은 연출·기믹 snapshot을 보낸다.

```json
{
  "effect_values": {"heal_all": 2, "party_guard": 2, "revive_count": 1},
  "mechanic_summary": "전원 보호 2 · 전원 회복 2 · 긴급 소생 1",
  "presentation_tier": 3,
  "vfx_intensity": 1.14,
  "audio_layer": "signature",
  "camera_profile": "ultimate",
  "emotion_vfx_primary": "#FFD48A",
  "emotion_vfx_secondary": "#FF8FA8"
}
```

보스 payload는 현재 index/count/name/tone, 의도 위력 보정, 다음 전환 장벽을 제공한다.
앱은 이 값으로 `P3/3 · 최종 말소`처럼 표시하고 문자열 이름으로 페이즈를 추측하지 않는다.

## 15. 남은 제작 순서

1. 백화·세렌 고유 I의 6구간 전용 sprite를 우선 제작한다.
2. 고유 II는 T1과 T3 contact 실루엣 차이를 먼저 확정하고 중간 프레임을 보간한다.
3. 12종 고유 I → 12종 고유 II → 감정 선택기 6종 → 스킬북 순으로 A gate를 닫는다.
4. 각 4 family마다 밝음/어두움, 48px, 저감 모션, 무음, 실제 기기 p95를 검수한다.
5. 전용 sprite가 없는 family는 fallback을 유지하되 완료율을 숨기지 않는다.

이 순서면 이미 완성된 판정과 성장 구조를 흔들지 않고, 사용자가 가장 자주 보는 신규
캐릭터 연출부터 품질을 끌어올릴 수 있다.
