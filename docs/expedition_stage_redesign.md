# 몽그루 스테이지·전투 UI 개편 설계서

최종 갱신: 2026-08-08
상태: 구조 개편 확정 계약 — **UI·콘텐츠 구조에 한해 기존 문서보다 우선한다**
대상 버전: `stage-battle-v2.0`
관련 문서: `docs/interactive_adventure_design.md`, `docs/expedition_manual_combat.md`,
`docs/character_skill_growth_design.md`, `docs/expedition_story_design.md`,
`docs/guardian_raid_design.md`, `docs/expedition_player_experience_design.md`

이 문서는 던전·전투의 **화면 문법과 진행 구조**를 개편한다. 계기는 명확한 사용자
피드백이다 — "플레이하기 어렵고, 정신사납고, 콘텐츠가 뭔지 모르겠다. 세븐나이츠·
몬스터 길들이기·포켓몬스터 같은 것을 기대했다." 이 문서는 그 기대를 몽그루의
불변식 위에서 구현 가능한 계약으로 바꾼다.

바꾸는 것은 무대와 진행 구조다. 스킬·레벨·진화·역할·기록서·경제·서사·안전 계약은
기존 문서 그대로이며, 이 문서와 충돌하는 것은 **화면·진행 조항뿐**이다. 충돌 목록은
2장에 전부 명시했고, 표에 없는 조항은 개정되지 않았다.

## 문서 적용 전제

1. 본편은 마음 일기다. 개편 후에도 일일 XP 50·일기 우선 보상 순서는 그대로다.
2. "세상에 나쁜 감정이 없다"와 무손실·무확률·무과금 격차 원칙은 화면이 바뀌어도
   바뀌지 않는다.
3. 레퍼런스에서 가져오는 것은 **화면 문법과 진행 구조**다. 타사 IP의 아트, 캐릭터,
   기술명, 사운드, 수치를 복제하지 않는다.
4. 서버 권위 판정·멱등·리플레이 계약은 유지한다. 개편은 클라이언트 표현과 콘텐츠
   배치의 문제다.
5. 접근성 기준(스크린리더, 48dp, 320px·200%, 모션 감소)은 새 화면에도 전부 적용된다.

## 0. 확정 결정 요약

| 항목 | 결정 |
|---|---|
| 기본 진행 | 노드 그래프 지도 → **스테이지 지도**. 지역당 8스테이지, `기억서고 3`처럼 지역명+번호로 표기 |
| 스테이지 구성 | 지역당 전투 4 + 이벤트 2 + 쉼터 1 + 수호짐승 보스 1 |
| 일반 적 | 신규 존재 `엉킴` 12종(지역당 3종). 쓰러짐 표현 없이 `풀려남`으로 처리 |
| 전투 화면 | 세로 3존 — 상단 적 무대 / 중단 아군 대치 / 하단 스킬 카드 독 |
| 명령 방식 | 전원 예약 후 일괄 확정 → **순차 명령·즉시 연출**. 순서 선택의 전략은 유지 |
| 명령 UI | 버튼+팝업 목록 → 행동 대원의 카드 직노출(기본 공격·고유·기록서·지키기, 최대 5장) |
| 표준 장비 | AUTO(보조/연속), 배속 1×/2×, 짧은 연출 모드를 전투 화면 고정 토글로 제공 |
| 정보 밀도 | 전투 중 상시 자원은 HP·집중력 2개. 계산 근거·상세 수치는 길게 누르기로 후퇴 |
| 탐험 자원 | 길빛·준비도는 스테이지 루프에서 쓰지 않는다. 탐사 모드(심화)에만 잔존 |
| 노드 지도 탐험 | 삭제하지 않는다. 지역 완주 후 열리는 `깊은 조사(탐사)`로 재배치 |
| 이벤트·스토리 | 사건 40종은 이벤트 스테이지로, run_thread 12종은 스테이지 전후 1줄 컷으로 흡수 |
| 경제 | 스테이지 클리어 보상은 기존 일일 보상 lane과 수치를 그대로 사용. 신규 재화 0 |
| 별점 | 만들지 않는다. 클리어 마크 + 이야기 마크 + 개인 기록만 |

## 1. 문제 진단 — 무엇이 정신사나운가

현 설계를 사용자 눈으로 다시 보면 문제는 여섯 개다.

| # | 문제 | 원인 조항 |
|---|---|---|
| 1 | 자원이 많다 | 길빛(이동) + 준비도(사건) + 집중력(전투) + HP가 한 판에 모두 등장 |
| 2 | 지도가 게임 같지 않다 | 추상 노드·간선 그래프, 숨은 간선, 가변 간선 — 보드게임 문법 |
| 3 | 읽을 게 많다 | 사건 본문 90자 + 선택 3개 + 능력치·DC 계산 근거 상시 노출 |
| 4 | 전투 입력이 무겁다 | 3명 전원 명령 예약 → 순서 조정 → 확정 → 일괄 해결. 첫 피드백까지 입력 6~9회 |
| 5 | 뭘 하면 되는지 모른다 | 순찰·보상 탐험·자유 탐험·개척·수호전·난이도 3종이 같은 층위로 나열 |
| 6 | 진행이 안 보인다 | "몇 번째 방"은 있어도 `버섯 숲 - 6` 같은 보편적 진행 표기가 없다 |

원인은 개별 화면이 아니라 **문법 선택**이다. 현 설계는 로그라이트·보드게임 문법
(자원 관리, 그래프 탐색, 텍스트 선택지)이고, 사용자가 기대한 것은 모바일 수집형
RPG 문법(스테이지, 대치 전투, 스킬 카드)이다. 따라서 수선이 아니라 문법 교체가
필요하고, 기존 문법의 콘텐츠는 버리지 않고 심화 모드로 옮긴다.

### 레퍼런스에서 가져오는 구조 원칙

| 레퍼런스 | 가져오는 구조 | 몽그루 번역 |
|---|---|---|
| 세븐나이츠류 | 하단 스킬 카드 독, 자동 스킬·짧은 연출·간단 모드 토글, 파티가 화면의 주인공 | 대원 카드 직노출 독, AUTO·배속·짧은 연출 고정 토글 |
| 몬스터 길들이기류 | `버섯 숲 - 6` 스테이지 표기, 필드 위 몬스터와 즉각 전투, Auto/2x | `기억서고 3` 표기, 엉킴과의 웨이브 전투 |
| 포켓몬스터 | 명령 프롬프트("무엇을 할까?"), 의도·상성의 읽기 쉬운 표시, 한 명씩 명령 | `뽀또는 무엇을 할까요?` 프롬프트, 의도 아이콘+숫자, 순차 명령 |

## 2. 기존 계약 개정표

이 문서가 명시적으로 개정하는 조항. 여기 없는 조항은 전부 유효하다.

| 기존 조항 | 원문 위치 | 개정 | 대체 가드레일 |
|---|---|---|---|
| 노드 그래프 지도가 기본 진행 | 탐험 설계서 5장 | 스테이지 지도가 기본. 노드 탐험은 지역 완주 후 `깊은 조사(탐사)`로 이동 | 탐사 모드는 기존 계약 전체를 그대로 유지. 필수 경로·보상은 스테이지만으로 완결 |
| 길빛·준비도 자원 | 탐험 설계서 4.2 | 스테이지 루프에서 미사용 | 탐사 모드 한정으로 잔존. 전투 자원은 HP·집중력 2개 |
| 전원 예약 → 일괄 확정 | 수동 지휘 계약 3 | 순차 명령·즉시 연출. 남은 대원 중 다음 행동자를 매번 고른다 | 순서 선택 = 집중력 공유 전략은 그대로. 서버는 라운드 단위 검증 유지 |
| 공격/스킬/마음 지키기 3버튼 + 스킬 팝업 목록 | 수동 지휘 계약, 스킬 성장 설계서 2.2 | 행동 대원의 카드 직노출(최대 5장). 팝업 단계 제거 | 카드 수 상한 5로 화면 예산 고정. 잠긴 카드는 사유와 함께 흐리게 |
| 4:3 전투 무대, 전경 40%/수호자 62% | 수동 지휘 계약 6 | 세로 3존 레이아웃(6장) | 연출 예산·접근성 기준은 그대로 승계 |
| 계산 근거 상시 전부 공개 | 탐험 설계서·스킬 설계서 여러 곳 | 기본 뷰는 결과 요약만, 근거는 길게 누르기 상세로 | 정보 자체는 삭제하지 않는다. 상세 뷰가 기존 전체 근거를 유지 |
| 탐험 허브의 모드 나열 | 탐험 설계서 10.1 | `이어서 모험` 중심의 허브(5.1)로 교체 | 순찰·개척·탐사는 하위 진입점으로 유지 |

## 3. 새 콘텐츠 구조 — 스테이지

### 3.1 지역과 스테이지

네 지역(기억서고·우물정원·보관고·관측실)과 해금 순서, stage 요구는 그대로 두고
각 지역을 8개 스테이지로 구성한다.

| 번호 | 종류 | 내용 | 예상 시간 |
|---:|---|---|---:|
| 1 | 전투 | 엉킴 웨이브 1 (배우기) | 60~90초 |
| 2 | 이벤트 | 사건 1개를 필드 연출로 | 30~60초 |
| 3 | 전투 | 엉킴 웨이브 2 | 90~120초 |
| 4 | 전투 | 큰 엉킴 (중간 보스) | 90~150초 |
| 5 | 쉼터 | 회복 + 관계 beat + 이야기 | 20~40초 |
| 6 | 이벤트 | 사건 1개 (지역 장치) | 30~60초 |
| 7 | 전투 | 엉킴 혼합 웨이브 2 | 90~150초 |
| 8 | 보스 | 수호짐승 수호전 | 90~180초 |

- 표기는 `기억서고 3`처럼 지역명 + 번호. 진행 바는 `3/8`을 항상 보여 준다.
- 한 스테이지는 독립 세션이다. 언제 끊어도 스테이지 단위로 저장되고, 하루에 몇
  스테이지를 하든 자유다. 8개를 한 번에 밀 필요가 없다.
- 클리어한 스테이지는 자유롭게 재도전할 수 있다(연습·이야기 다시 보기). 보상은
  기존 일일 보상 lane 규칙을 그대로 따르므로 반복 이득이 없다.
- 지역 8 클리어 = 지역 완주. 완주 시 `깊은 조사(탐사 모드)`와 다음 지역이 열린다.
  기존 "지역 최초 완주" 보상·도감·해금 계약은 스테이지 8 클리어에 그대로 매핑한다.

### 3.2 run_thread와 이벤트의 재배치

- run_thread(스토리 설계서 6장)의 beat를 스테이지에 고정 매핑한다:
  `seed`는 스테이지 1~2 진입 컷, `echo`는 4~6 사이 컷, `payoff`는 8 클리어 컷.
  변형 선택 규칙(approach 매핑)은 그대로 쓰되, approach는 이벤트 스테이지의 선택과
  전투 스타일(방어 비중 등 관찰 가능한 행동)로 계산한다.
- 컷은 1~2문장 + 일러스트 배경이며 탭 한 번으로 넘어간다. 컷 자동 재생은 스테이지당
  1회, 다시 보기는 도감에서.
- 일반 사건 40종은 이벤트 스테이지의 원고 풀이 된다. 한 지역의 이벤트 스테이지
  2곳이 재도전마다 사건 풀에서 다른 사건을 보여 주므로 반복 신선도가 유지된다.
- 발견 장면·도감·유대·수집품 계약은 변화 없다. 사건이 주던 발견은 이벤트
  스테이지가 그대로 준다.

### 3.3 일반 적 — 엉킴

전투 스테이지의 상대. "세상에 나쁜 감정이 없다" 원칙에 맞는 존재로 정의한다.

- 엉킴은 관리인의 손이 못 닿아 **엉켜 버린 지역의 물건들**이다. 악의가 없고,
  전투는 무찌르기가 아니라 **풀어 주기**다. HP 0 연출은 소멸·사망이 아니라 엉킴이
  스르르 풀리며 원래 물건(장부 한 권, 방울 하나, 씨앗함 하나)으로 돌아가는 것이다.
- 지역당 3종 × 4지역 = 12종. 구성: 일반 엉킴 2종 + 큰 엉킴 1종(중간 보스).

| 지역 | 일반 엉킴 | 큰 엉킴 |
|---|---|---|
| 기억서고 | 엉킨 장부 뭉치, 표류 압화 떼 | 서가 뒤엉킴 |
| 우물정원 | 매듭진 메아리, 튀는 물방울 떼 | 소용돌이 종매듭 |
| 보관고 | 뒤엉킨 별가루, 구르는 씨앗함 | 거꾸로 선 시계태엽 |
| 관측실 | 얽힌 나이테 조각, 흩어진 기록 낱장 | 헝클어진 관측기 |

- 엉킴도 의도 예고·약점 순환을 가진다(수호전과 같은 판정 문법). 다만 예고는
  1개, 위력 1~2로 단순하다. 배우는 난도를 웨이브에서 올리고 보스에서 완성한다.
- 엉킴 전투의 승률 밴드: 스테이지 1~7은 `gentle`(90~100%), 큰 엉킴은 90% 내외,
  수호짐승 보스는 기존 지역 수호전 밴드를 그대로 쓴다.
- 에셋: 종당 idle·hit·풀림 3동작. 몬스터를 무섭게 그리지 않는다 — 뭉치고 엉킨
  실루엣에 눈만 붙은, 곤란해 보이는 인상이 기준이다.

### 3.4 모드 정리 — "오늘 뭘 하면 되는지"

| 층위 | 이름 | 역할 |
|---|---|---|
| 기본(항상 보임) | **모험** | 스테이지 진행. `이어서 모험하기 — 기억서고 5` 한 줄이 전부 |
| 기본(항상 보임) | 자동 순찰 | 기존 그대로. 방치 수집 |
| 완주 후 | 깊은 조사(탐사) | 기존 노드 지도 탐험 전체. 3등급 기록서 도전이 여기 있다 |
| 완주 후 | 합동 수호전 | 6인 깊은 꿈. 기존 설계서 그대로, 전투 화면만 이 문서를 따른다 |
| 우물정원 완주 후 | 장거리 개척 | 기존 그대로 |

- 난이도 선택지를 기본 루프에서 없앤다. 스테이지 자체가 난이도 곡선이다.
  `standard/deep` 구분은 탐사 모드에만 남는다.
- 허브 화면은 "지금 누를 것 하나"를 크게, 나머지를 작게 배치한다(5.1).

## 4. 새 전투 문법

### 4.1 순차 명령 루프

```text
라운드 시작: 적 의도·약점 공개
  → "누가 먼저 할까요?" — 남은 대원 중 한 명 탭
  → 그 대원의 카드 독에서 카드 1장 탭
  → 즉시 실행·연출 (760ms 예산 유지)
  → 남은 대원 반복 (2명 → 1명)
  → 전원 행동 후 적 행동 (예고대로)
  → 다음 라운드 또는 종료
```

- 첫 입력에서 첫 피드백까지 **탭 2회**다(대원 탭 → 카드 탭). 기존 예약형의
  6~9회에서 줄인다.
- 순서 전략은 그대로 살아 있다. 누구를 먼저 행동시키느냐가 집중력 생성·사용
  순서이고, `front` 의도는 첫 행동 대원을 노린다는 규칙도 유지한다.
- 아직 행동하지 않은 대원의 카드 독을 미리 볼 수 있지만 실행은 현재 대원만 된다.
- 되돌리기: 실행 전 카드 선택은 자유롭게 취소·변경. 실행된 행동은 되돌리지 않는다.
- 서버 계약: `POST /expeditions/{run}/combat/turns`를 대원 단위 부분 제출로
  확장한다(`actions[1]` + `round_seq`). 서버는 라운드 내 누적·검증하고, 구버전
  일괄 제출도 계속 받는다. 멱등·revision·계산 trace 계약은 그대로다.

### 4.2 카드 독

행동 대원이 정해지면 하단 독에 그 대원의 카드가 직접 나열된다. 팝업이 없다.

| 카드 | 내용 | 항상 표시 |
|---|---|---|
| 기본 공격 | 집중력 +1 생성 | 예상 피해 |
| 고유 스킬 | 고유 II (tier 반영) | 집중력 비용, 예상 효과 한 줄 |
| 기록서 1~2 | 장착한 전투형 기록서 | 비용·남은 횟수 |
| 마음 지키기 | 방어 2, 집중력 +1 | 막을 피해 |

- 최대 5장, 카드 하나 = 최소 64dp. 5장이 안 되는 화면 폭에서는 가로 스크롤이
  아니라 2줄 접힘.
- 잠긴 카드(집중력 부족·조건 미충족·횟수 소진)는 흐리게 + 사유 한 단어
  (`집중 부족`). 길게 누르면 전체 설명.
- 카드 위 한 줄 프롬프트: `뽀또는 무엇을 할까요?` 행동 대원이 바뀔 때마다 갱신되고
  스크린리더가 가장 먼저 읽는다.
- T3 조건이 켜진 카드는 테두리 발광 + `지금이에요` 배지. 색만으로 구분하지 않는다.

### 4.3 읽기 쉬운 적 표시

- 적 머리 위: 의도 아이콘 + 대상 표시 + 위력 숫자. 포켓몬의 상성 배지처럼 약점
  공명 아이콘을 HP 바 옆에 상시 표시한다.
- 약점과 일치하는 카드에는 독에서 같은 공명 아이콘이 반짝인다. "이 카드가 지금
  좋다"를 계산 없이 알게 한다.
- 피해 숫자는 크고 짧게(600ms), HP·장벽 바는 즉시 감소 + 잔상 감소의 2단 표현.

### 4.4 표준 장비 토글

전투 화면 우상단 고정 3종. 상태는 계정 설정으로 저장된다.

| 토글 | 동작 |
|---|---|
| AUTO | 기존 보조/연속 계약 그대로. 선택 이유를 로그에 남긴다 |
| 배속 | 1× / 2×. 연출 타임라인 스케일이며 프레임 스킵·판정 변화 없음 |
| 짧은 연출 | 시동·여운 프레임 축약(약 40% 단축). `disableAnimations`와 독립 옵션 |

### 4.5 유지되는 전투 계약

의도·약점 사전 공개, 공유 집중력 3/최대 5, 공명 4종·약점 +7, 6라운드 상한과 안전
귀환, 등급 bp·tier·기록서 스냅샷, AUTO 공정성(숨은 보정 0), 죽음 표현 금지, 서버
권위·멱등·리플레이 — 전부 그대로다. 합동 수호전의 교대·결정적 순간도 이 화면
문법 위에서 그대로 동작한다.

## 5. 화면 계약

### 5.1 모험 허브

- 최상단 카드 하나: `이어서 모험하기 — 기억서고 5` + 파티 초상 3개. 탭 한 번에
  파티 확인 화면으로.
- 그 아래 한 줄: 오늘의 첫 클리어 보상 상태(`오늘 일기를 써서 마음 공명이
  준비됐어요` / `자유 모험 중`). 기존 보상 lane 규칙의 표시일 뿐 새 규칙이 아니다.
- 하단 작은 진입점: 자동 순찰 · 깊은 조사 · 합동 수호전 · 장거리 개척(해금 순).
  잠긴 항목은 해금 조건 한 줄과 함께 흐리게.
- 배지·빨간 점으로 재촉하지 않는다. 유일한 알림은 관리인 편지(기존 계약)뿐이다.

### 5.2 스테이지 지도

- 지역 배경 일러스트 위에 스테이지 점 8개가 완만한 길로 이어진다. 현재 위치에
  선두 캐릭터 토큰이 서 있다.
- 스테이지 점: 전투(발자국), 이벤트(말풍선), 쉼터(모닥불), 보스(짐승 실루엣)
  아이콘 + 번호. 클리어는 체크, 이야기 컷을 안 봤으면 책갈피 마크.
- 상단 바: `이끼 낀 기억서고 · 5/8` + 뒤로가기. 그 외 상시 UI 없음.
- 스테이지 탭 → 하단 시트: 종류, 등장 엉킴·약점 미리보기, 예상 시간, `출발` 버튼.
  시트에서 파티·프리셋을 바꿀 수 있다.
- 별점·점수·랭킹 없음. 개인 기록(최단 라운드·무피해)은 상세에서만 보인다.

### 5.3 전투 화면 — 세로 3존

390×844 기준. 가로 모드는 좌우 대치로 같은 존을 재배열한다.

```text
┌─────────────────────────────┐
│ [지역 5/8]      [AUTO|2×|短] │  상단 정보 바 (høyde 8%)
│                             │
│        적 무대 (32%)         │  엉킴/짐승 + HP·장벽 바
│   의도 아이콘·약점 공명 상시   │
│                             │
│        아군 무대 (30%)        │  대원 3명 + HP·집중력
│   행동 대원이 반 보 앞으로     │
│                             │
│ 「뽀또는 무엇을 할까요?」      │  프롬프트 (6%)
│ [공격][고유][기록서][지키기]   │  카드 독 (24%)
└─────────────────────────────┘
```

- 적 무대와 아군 무대를 합쳐 화면의 62%가 캐릭터다. 숫자·패널이 주인공을 가리지
  않는다.
- 집중력은 아군 무대 아래 구슬 5개 한 줄이 유일한 표시다. 만들면 차오르고 쓰면
  비는 애니메이션으로 공유 자원임을 보여 준다.
- 상세 정보(계산 근거, tier 효과 전문, bp)는 카드·대원·적 어디든 길게 누르면
  같은 형식의 반투명 시트로 열린다. 시트가 열려도 전투 화면을 벗어나지 않는다.
- 합동 수호전에서는 아군 무대 아래에 후열 3명의 소형 대기 카드 줄이 추가되고
  나머지는 동일하다.

### 5.4 이벤트 스테이지

사건을 카드 텍스트가 아니라 **필드 위 장면**으로 보여 준다.

- 배경 일러스트 + 사건 오브젝트(빛나는 서랍, 울리는 종) + 파티 토큰이 한 화면.
- 사건 본문은 말풍선 1개(90자 계약 유지). 선택지는 하단에 큰 버튼 2~3개로,
  각 버튼에 `어울리는 힘: 관찰` + 성공 예상(`확실해요/해 볼 만해요/어려워 보여요`
  3단)만 표시한다. 정확한 수치·계산 근거는 길게 누르기 상세로.
- 판정 연출: 선택한 대원이 오브젝트로 다가가 행동하는 600~900ms 연출 후 결과
  말풍선. 주사위·확률 연출은 없다(판정은 기존처럼 결정적).
- 성공/부분 성공/우회의 결과 문법과 보상 계약은 기존 사건 규칙 그대로다.

### 5.5 결과 화면

- 1초: 큰 `클리어!` + 파티 포즈 → 2~6초: 얻은 것(발견·수집품·XP·씨앗)이 한
  줄씩 → 이후: 다음 스테이지 미리보기 한 장.
- 기존 25초 결과 공개 계약의 순서(이야기 → 발견 → 경제)를 유지하되 스테이지
  단위라 총량이 짧아진다.
- 버튼은 `다음 스테이지` / `지도로` 2개. 재촉 타이머 없음.

## 6. 시뮬레이션·검증

- 승률 밴드: 스테이지 1~7 gentle 90~100%, 큰 엉킴 88~95%, 보스는 기존 지역
  수호전 밴드. 탐사·합동 수호전 밴드는 각 문서 그대로.
- 입력 수 계약: 전투 1라운드의 최소 탭 수 6회(3명 × 2탭) 이하, 이벤트 스테이지
  1회차 완료까지 탭 4회 이하. 이를 UI 테스트로 고정한다.
- 첫 세션 계약: 신규 사용자가 튜토리얼 포함 10분 안에 `기억서고 3`까지 도달할 수
  있어야 한다(중앙값). 넘으면 스테이지 1~3의 웨이브·문구를 줄인다.
- 이해도 검증: 출시 전 신규 5인 테스트에서 "지금 뭘 하면 되는지" 질문에 5초 안에
  답하지 못한 화면은 출시 차단이다(허브·지도·전투·이벤트 각각).
- 성능: 세로 3존 전투에서 기존 기준(p95 16.7ms, 캐시 24MiB, 25ms 초과 0)을
  그대로 통과해야 한다.

  테이블은 건드리지 않는다.
- 기능 플래그 `stage_mode`로 단계 배포한다. OFF면 기존 화면이 그대로 산다.

  경제 보상을 만들지 않는다(통합 테스트 5건). 앱: `허브 → 스테이지 지도 →
  편성` 3단 셸을 만들고 `이어서 모험하기 — 기억서고 N` 카드, 8점 지도(종류
  아이콘·클리어 체크·이야기 책갈피·진행 바), 상세 시트(등장 엉킴·약점·예상
  시간·출발), 잠긴 점의 사유 노출을 구현했다. 뒤로가기는 한 단계씩 돌아온다.
  `flutter analyze` 0건, 앱 281·서버 363 테스트 통과.
- 남은 것: 스테이지 1~7의 전용 엉킴 웨이브와 이벤트 스테이지 연출은 S3에서
  교체한다. 현재는 각 스테이지가 기존 지역 run을 그대로 실행하며 완주 시
  해당 스테이지가 클리어로 기록된다.
- 다음: S3 엉킴 12종 에셋·웨이브 전투·이벤트 스테이지, 그리고 신규 5인
  이해도 테스트(§6의 10분 도달 계약 포함).

## 9. 금지하는 지름길

- 스테이지에 별점·점수·랭킹·스태미나·소탕권을 붙이는 것
- 엉킴을 처치·사냥 언어로 부르거나 소멸 연출을 넣는 것
- 스테이지 반복에 새 경제 보상을 붙여 그라인딩을 만드는 것
- 입력을 줄인다는 이유로 의도·약점 공개를 숨기는 것
- 짧은 연출 모드에서 판정 정보(누가 무엇을 했는지)까지 생략하는 것
- 상세 정보를 후퇴시키면서 아예 삭제해 투명성 계약을 깨는 것
- 탐사 모드를 조용히 방치해 3등급 기록서 획득 경로를 사문화하는 것
- 레퍼런스 게임의 아트·이펙트·사운드·명칭을 그대로 옮기는 것
- 기존 진행 중 run을 강제 전환·삭제하는 것
- 허브에 빨간 점·카운트다운을 붙여 스테이지를 숙제로 만드는 것

## 부록 A. 개편 전후 한 판 비교

**개편 전** — 허브에서 보상 탐험 선택 → 난이도 선택 → 노드 지도에서 간선 확인 →
길빛 계산 → 이동 → 사건 카드 본문·선택 3개·DC 읽기 → 판정 → … → 수호전에서
3명 명령 예약·순서 조정·확정 → 일괄 연출. 첫 전투 피드백까지 수 분.

**개편 후** — 허브에서 `이어서 모험하기 — 기억서고 3` 탭 → 출발 → 엉킨 장부
뭉치가 나타남 → `뽀또는 무엇을 할까요?` → 뽀또 탭, 공격 카드 탭 → 즉시 연출,
집중력 구슬 +1 → 블루미 탭, 고유 카드 탭 → … → 적 행동 → 2라운드에 풀려남 →
`클리어!` → 다음 스테이지 미리보기. 첫 피드백까지 탭 4회·20초.
