# Mongroo

**一款写日记、养角色，还能带着伙伴去冒险的游戏。**

记下每天的经历，角色就会一点点长大。你可以带着养大的伙伴去探险，也可以收集新角色，装饰自己的房间。

## 日记写几句就好

把想记住的事随手写下来。保存日记后，你会获得经验值，角色也会随之成长。写下难过或生气的事，不会让你少拿经验或奖励。

点击日历上的日期，就能重读或修改以前的日记。每周和每月的回顾，也能帮你看看这段时间的心情变化。

## 18种角色，养出不同的模样

角色从一颗种子开始，经历5个成长阶段。日记中的情绪会让它们形成6种不同的类型，外形和说话方式也会变化。没有哪一种情绪能让角色长得更快，或换来更多奖励。

角色长大后，可以收入博物馆，再种下一颗新种子。用收集到的伙伴组队探险，试试它们各自的技能吧。

## 完成每日任务，解锁喜欢的角色

完成每日任务可以获得经验值和游戏内货币**种子**。攒下种子，就能购买新角色、服装和房间装饰。每件物品的价格和购买条件都会提前显示，可以直接选择自己想要的，没有抽卡。

## 带上伙伴，一起去冒险

四片区域，共32个关卡。在地图上选好目的地后，就可以亲自操控角色探索，寻找沿途的故事。

战斗时，先看清敌人下一步要做什么，再选择攻击、防御或技能。长按技能可以查看详细说明。设置中还可以开启自动战斗、调整战斗速度，以及调节音乐、音效和动画效果。

## 布置自己的房间

换一种房间主题，添几件小摆设，再给角色换身衣服。用游玩时攒下的种子，慢慢把喜欢的东西带回家。

## 注册前，先试试看

启动游戏后，在登录页选择 **회원가입 없이 3분 체험**（免注册体验3分钟），就能试试写日记和培养角色。体验期间的日记只保存在当前设备上，不会上传到服务器。之后即使注册账号，这些记录也不会自动转入账号。

所有截图和GIF均使用测试账号实际游玩后录制。
