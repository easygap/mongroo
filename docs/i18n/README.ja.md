# Mongroo（モングル）

**日記を書いてキャラクターを育て、一緒に冒険するゲームです。**

その日の出来事を書くと、キャラクターが少しずつ育ちます。育てた仲間と冒険に出かけたり、新しいキャラクターを集めたり、自分好みの部屋に模様替えしたりして楽しめます。

## 日記は一言から

覚えておきたい出来事を、気軽に書いてみてください。日記を保存すると経験値が入り、キャラクターが育ちます。悲しかったことや腹が立ったことを書いても、経験値や報酬が減ることはありません。

過去の日記はカレンダーの日付をタップして、読み返したり書き直したりできます。1週間・1か月ごとの振り返りでは、その間の気分の変化も見られます。

## 全18種のキャラクターを育てよう

キャラクターは種から5段階で成長します。日記に表れた感情によって6つのタイプに分かれ、見た目や話し方も変わります。特定の感情を書いたほうが早く育ったり、報酬が増えたりすることはありません。

育ちきったキャラクターはミュージアムに残して、次の種を植えられます。集めた仲間でパーティーを組み、それぞれのスキルを試してみてください。

## クエストをクリアして、好きなキャラクターを選ぼう

デイリークエストをクリアすると、経験値とゲーム内通貨の**種**が手に入ります。種を貯めて、新しいキャラクターや衣装、部屋の飾りを購入できます。価格と条件を確認してから選べる仕組みで、ガチャはありません。

## 仲間と一緒に冒険へ

4つのエリアに、全32ステージを用意しています。マップで行き先を選んだら、キャラクターを自分で動かして探索しましょう。道中では、さまざまな出来事や物語に出会えます。

バトルでは敵の次の攻撃を見てから、攻撃・防御・スキルを選びます。スキルを長押しすると詳しい説明を確認できます。オートバトルや倍速のほか、BGM・効果音・アニメーションの設定も変更できます。

## 部屋も自分好みに

部屋のテーマを変えたり、小物を飾ったり、キャラクターを着せ替えたり。遊びながら貯めた種で、お気に入りを少しずつ揃えられます。

## アカウント登録前にお試し

アプリを起動したら、ログイン画面の **회원가입 없이 3분 체험**（登録なしで3分間お試し）から、日記とキャラクターの成長を体験できます。お試し中の日記は端末内に保存され、サーバーには送信されません。後からアカウントを登録しても、自動では引き継がれません。

画像とGIFはすべて、テスト用アカウントで実際にプレイして撮影したものです。
