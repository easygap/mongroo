# 몽그루 캐릭터 스킬·레벨·진화 확장 설계서

최종 갱신: 2026-08-07
상태: 확장 제안 확정안
대상 버전: `character-skill-growth-v1`
관련 문서: `docs/interactive_adventure_design.md`, `docs/expedition_skill_tree_catalog.md`,
`docs/expedition_manual_combat.md`, `docs/expedition_player_experience_design.md`,
`docs/design.md`, `docs/content_strategy.md`, `design-system/ADVENTURE_ASSET_PROMPTS.md`

이 문서는 캐릭터가 가진 스킬을 `고유 2 + 교체 2` 네 슬롯으로 확장하고, 스킬북 획득
경로, 레벨별 능력치, 성장 단계 진화, 상점 등급과 성능의 관계, 라이브 밸런스 운영을
하나의 계약으로 고정한다. 구현 중 세부 판단이 필요하면 이 문서를 우선하고, 여기서
정하지 않은 것은 `interactive_adventure_design.md`의 불변식을 그대로 따른다.

## 문서 적용 전제

몽그루의 본편은 여전히 마음 일기다. 이 문서가 스킬과 수치를 상세히 다루는 이유는
캐릭터를 강하게 만들기 위해서가 아니라, **오래 기록한 시간이 눈에 보이는 형태로
돌아오게 하기 위해서**다. 다음 다섯 줄은 이 문서의 모든 수치보다 우선한다.

1. 레벨·진화·스킬북은 하루 XP 50, 씨앗 상한, 일기 우선 보상표를 절대 바꾸지 않는다.
2. 무료 스타터 캐릭터 한 명과 정원 길잡이만으로 모든 필수 콘텐츠를 완주할 수 있다.
3. 씨앗은 현금으로 살 수 없다. 비싼 캐릭터는 과금이 아니라 **기록한 날의 수**로 산다.
4. 강해진다는 감각은 숫자 인플레가 아니라 **선택지가 늘어나는 것**으로 만든다.
5. 확률형 획득, 강화 실패, 재화 소각, 시즌 초기화는 어떤 형태로도 만들지 않는다.

## 0. 확정 결정 요약

| 항목 | 결정 |
|---|---|
| 스킬 슬롯 | 캐릭터당 4개. 고유 2개(교체 불가) + 스킬북 2개(교체 자유) |
| 고유 스킬 구성 | 고유 I은 탐험 공간, 고유 II는 수호전 공간. 기존 구현을 그대로 승계 |
| 진화 | 고유 스킬이 stage 2/4/5에 T1→T2→T3로 진화. 새 버튼을 늘리지 않음 |
| 레벨 | 1~30. 마음 일기 누적 exp에서 파생하는 읽기 전용 값. 별도 탐험 XP 없음 |
| 레벨의 효과 | 단계 내 능력치 +1 1회, 수호전 HP·위력 계수, 슬롯·진화 해금 조건 |
| 등급과 성능 | 등급은 **성능 총량**이 아니라 **성장 곡선의 기울기와 조건 구조**를 산다 |
| 등급 격차 | 같은 레벨 기대 성능 차이 최대 10%, 어떤 조합에서도 위력비 1.35배 이내 |
| 스킬북 | 3개 등급 36종. 상점 구매 20·해금 조건 8·탐험 최초 달성 8. 확률 드롭 없음 |
| 스킬북 예산 | `effect_budget` 1~2, `reward_affecting: false`, 계정 라이선스 1장 |
| 재화 | 씨앗 단일 통화. 새 통화·강화석·승급 재료를 만들지 않음 |
| 적 스케일링 | 수호자 장벽만 파티 성장의 60% 비율로 따라옴. 순 우위는 남기되 상한 고정 |
| 이펙트 | 등급은 화려함이 아니라 **전용 제작 시트 수**를 산다. 파티클·시간 예산은 동일 |
| 밸런스 패치 | 6주 pack + 2주 hotfix 창. 하향 시 7일 전액 환불·무료 재배분 |
| 수확 캐릭터 | 수확 시점 레벨을 영구 보존. 주간 일기 목표로 최대 +3레벨까지 회향 각인 |
| 장기 콘텐츠 | pack마다 스킬북 4종 + 품종 1종 진화 연출 + 기존 지역 사건 4개를 함께 추가 |

## 1. 기존 불변식과 이 문서가 바꾸는 것

이 확장은 기존 문서의 규칙 세 줄을 명시적으로 개정한다. 개정하지 않은 규칙은 전부
그대로 유효하며, 개정한 자리에는 반드시 대체 가드레일을 둔다.

| 기존 규칙 | 원문 위치 | 이 문서의 개정 | 대체 가드레일 |
|---|---|---|---|
| 품종은 기본 능력치를 추가하지 않고 고유 스킬과 연출만 다르게 한다 | 탐험 설계서 3.3 | 유지. 등급 차등은 **탐험 4능력치가 아니라 수호전 위력 계수**에만 적용 | 탐험 `effective_stat` 계산식은 등급을 읽지 않는다. CI가 등급 인자 사용을 금지 |
| 능력치는 `3 + stage + 성장형 보정` | 탐험 설계서 3.3 | `+ 단계 내 성숙 보정(0 또는 1)` 추가 | 지역 상한 7~10과 필수 DC 13은 변하지 않는다. 보정 후에도 상한이 그대로 적용된다 |
| 노드로 고유·성장형 스킬 충전 횟수를 추가하지 않는다 | 스킬트리 카탈로그 7.3.1 | 트리 노드는 계속 금지. **진화 T3만** 쉼터 회복 대상에 고유 스킬을 포함 | run 전체에서 고유 스킬 회복은 1회. 성장형 스킬 회복 1회와 합쳐 run당 총 2회를 넘지 않는다 |
| 대원 HP는 3 | 수동 지휘 계약 4 | 레벨에 따라 3~6 | 적 위력은 성장으로 오르지 않는다. HP 상승은 전멸 위험만 낮추고 클리어 시간은 장벽 스케일이 담당 |

다음 규칙은 이 문서에서도 **절대 바꾸지 않는다**.

- 여섯 성장형의 능력 예산은 같다. 특정 감정이 유리해지는 경로를 만들지 않는다.
- 일일 XP 50, 일기 XP 40·씨앗 15가 단일 활동 최대치라는 순서를 유지한다.
- 스킬·스킬북·레벨·진화는 XP, 씨앗, 수집품 수량, 가치 예산을 1도 바꾸지 않는다.
- 특정 품종·등급·보유 수를 입장 조건이나 주간 제한으로 만들지 않는다.
- 캐릭터는 죽거나 잃어버리거나 퇴화하지 않는다. 스킬북도 파괴·소모되지 않는다.
- 확률형 상자, 강화 성공률, 행동력 충전, 입장권 판매를 만들지 않는다.

## 2. 네 슬롯 구조

### 2.1 슬롯 정의

| 슬롯 | 이름 | 공간 | 해금 | 교체 | 개수 |
|---|---|---|---|---|---:|
| `S1` | 품종 고유 · 길 | 탐험 지도·사건 | stage 2 | 불가 | 1 |
| `S2` | 품종 고유 · 수호 | 수호전 | stage 2 | 불가 | 1 |
| `B1` | 마음결 기록서 1 | 장착한 책의 공간 | stage 3 | 자유 | 1 |
| `B2` | 마음결 기록서 2 | 장착한 책의 공간 | stage 5 | 자유 | 1 |

성장형 스킬 6종은 슬롯을 차지하지 않는다. 성장형은 캐릭터가 고르는 것이 아니라
일기가 정하는 결이므로, 지금처럼 캐릭터에 붙어 있는 별도 행동으로 유지한다.

### 2.2 화면 버튼 예산은 늘리지 않는다

슬롯이 4개가 됐다고 탐험 화면 버튼을 4개로 만들지 않는다. 기존 계약을 그대로 지킨다.

| 화면 | 고정 버튼 | 나머지 스킬의 표현 |
|---|---|---|
| 탐험 지도·사건 | 고유 I, 성장형 스킬 두 개 | `B1`·`B2`의 탐험형 책은 스킬트리 노드와 같은 **문맥 칩** 한 줄로 나타난다 |
| 수호전 | 공격 / 스킬 / 마음 지키기 세 개 | `스킬`을 누르면 고유 II + 장착한 전투형 책이 최대 3항목 목록으로 열린다 |

문맥 칩과 스킬 목록은 유효한 상황에서만 나타나고 자동으로 소비되지 않는다. 한
확정 행동에 같은 `stack_group`을 두 개 겹칠 수 없다는 규칙도 그대로 적용한다.

### 2.3 잠금 표시 규칙

잠긴 슬롯은 숨기지 않고 이유를 문장으로 보여 준다. `줄기가 되면 기록서를 한 권
챙길 수 있어요`, `만개하면 두 번째 기록서를 펼 수 있어요`처럼 다음 목표를 알려
주되 남은 exp를 진행 바로 압박하지 않는다. 잠금 사유 문구는 서버가 내려 준
`lock_reason_key`를 앱·스크린리더가 같은 문구로 읽는다.

## 3. 레벨 시스템

### 3.1 레벨은 새로운 성장이 아니라 기존 exp의 눈금이다

탐험 XP, 전투 XP, 숙련 XP를 새로 만들지 않는다. 레벨은 이미 존재하는 식물 exp에서
파생하는 읽기 전용 값이며 `level_from_exp()`를 `stage_from_exp()` 옆의 단일 도메인
함수로 둔다. 마음 일기만이 레벨을 올리는 유일한 원본이라는 규칙이 이렇게 유지된다.

레벨을 도입하는 이유는 세 가지다. 첫째, stage 5단계만으로는 3주 넘게 기록해도
아무 변화가 없는 구간이 길다. 둘째, 만개(exp 450) 이후 수확 전까지 성장 피드백이
완전히 사라진다. 셋째, 진화·슬롯 해금 시점을 stage보다 촘촘하게 잡아야 "다음에 뭐가
열리지"라는 기대가 끊기지 않는다.

- stage 경계는 기존 `stage_from_exp()`의 0/20/100/250/450을 그대로 사용한다. 레벨
  표는 그 경계를 절대 옮기지 않는다.
- 하루 최대 exp가 50이므로 레벨 23(만개)까지 최소 12일, 레벨 30까지 최소 24일이
  걸린다. 실제 기록 빈도를 감안한 목표는 만개 3주, 레벨 30 5~7주다.
- 레벨 24~30 구간은 수확을 미룰 이유를 만든다. 수확하면 새 캐릭터를 심을 수 있으므로
  **오래 키우기와 새로 시작하기 사이에 진짜 선택**이 생긴다. 어느 쪽도 재화 우위가
  없다.

### 3.3 단계 내 성숙 보정

```text
raw_stat = 3 + stage + 성장형 보정 + maturity(level)
maturity(level) = 1 if level >= 해당 stage 구간의 하위 절반을 지났을 때 else 0
effective_stat = min(synced_stat, 지역 능력치별 상한)
```

- `maturity`는 0 또는 1만 가지며 한 stage 안에서 한 번만 오른다.
- 지역 상한(기억서고 7 ~ 관측실 10)은 그대로 적용된다. 보정이 붙어도 상한을 넘지
  않으므로 필수 DC 13 대비 최대 유효 능력치 10이라는 계약은 변하지 않는다.
- 실제 효과는 "상한에 조금 더 일찍 도달한다"이며 상한 자체가 오르지 않는다.
- UI는 `원래 8 · 성숙 +1 → 9`, `지역 상한 9`처럼 계산 근거를 계속 전부 공개한다.

### 3.4 탐험 판정에서 레벨을 더 크게 쓰지 않는 이유

레벨 30단계를 탐험 판정에 그대로 얹으면 상한 7~10, DC 8~13이라는 좁은 창에 즉시
붙어 버린다. 그러면 상한을 올릴 수밖에 없고, 상한을 올리면 "새 지역이 이전 캐릭터를
숫자로 폐기하지 않는다"는 핵심 약속이 무너진다. 따라서 레벨의 수치 성장은 상한이
없는 공간, 즉 수호전으로 보낸다. 탐험에서 레벨이 만드는 변화는 숫자가 아니라
**진화 tier와 기록서 슬롯이 여는 새로운 행동**이다.

### 3.5 수확 캐릭터와 회향 각인

- 수확 시점의 레벨을 `final_level`로 영구 보존한다. 박물관 캐릭터는 그 레벨로 계속
  탐험에 참가한다.
- 수확 뒤에도 최대 **+3레벨, 상한 30**까지 올릴 수 있는 `회향 각인`을 둔다.
- 각인 재료는 탐험이 아니라 **주간 마음 일기 3일 목표**의 부가 보상으로만 나온다.
  주 1개, 캐릭터 1명에게 사용한다. 탐험 반복으로 얻는 경로는 만들지 않는다.
- 회향 각인은 `stage`, `final_form`, `growth_persona`, 박물관 스냅샷을 바꾸지 않는다.
- 이미 레벨 30으로 수확한 캐릭터에게는 각인을 사용할 수 없고, 재료도 소비되지 않는다.

## 4. 진화

### 4.1 진화는 새 캐릭터가 아니라 같은 스킬의 다음 형태다

포켓몬형 진화의 재미는 "다른 것이 됐다"는 감각이다. 몽그루에서 외형 진화는 이미
stage 2~5 성장 원화가 담당하고 있다. 이 문서는 그 위에 **스킬의 진화**를 얹는다.
스킬 이름과 아이콘이 바뀌고, 연출이 한 단계 길어지고, 효과의 적용 범위가 넓어진다.
버튼 개수와 조작 방법은 바뀌지 않아서 다시 배울 필요가 없다.

### 4.2 진화 문법

모든 품종이 같은 문법을 쓴다. 품종마다 다른 것은 문장이지 규칙이 아니다.

| tier | 조건 | 탐험 고유 I이 얻는 것 | 수호전 고유 II가 얻는 것 |
|---|---|---|---|
| T1 | stage 2 (Lv 3) | 현재 구현된 기본 효과 | 현재 구현된 위력·효과 |
| T2 | stage 4 (Lv 16) | **대상 확장** — 자신→파티원, 인접→거리 2, 현재 사건→다음 사건 중 하나 | **부가 효과 1개** — 방어 1, 회복 1, 집중력 1, 피해 +4 중 품종별 하나 |
| T3 | stage 5 이후 Lv 25 | **회복 대상 포함** — run당 1회, 쉼터에서 고유 스킬 충전 1회 회복 가능 | **조건부 상위** — 품종 조건 충족 시 등급 계수 적용, 부가 효과가 파티 범위로 |

- T2는 수치를 올리지 않는다. 같은 크기의 효과를 더 쓸모 있는 자리에 놓게 한다.
- T3의 탐험 회복은 run 전체 1회이며, 기존 성장형 스킬 회복 1회와 합쳐 **run당 총
  2회**를 넘지 않는다. 쉼터를 오가며 무한 회복할 수 없다는 규칙은 그대로다.
- T3의 조건은 품종 정체성과 직결된 관찰 가능한 상태여야 한다. 숨은 확률은 없다.
- 진화는 되돌릴 수 없고, 되돌릴 이유도 없다. 하위 tier가 더 좋은 상황을 만들지 않는다.

### 4.3 진화 순간의 연출 계약

- 진화는 탐험 중에 일어나지 않는다. 일기를 써서 레벨이 오른 뒤 **홈 화면**에서 한
  번만 재생한다. 탐험 중 스냅샷은 시작 당시 tier를 유지한다.
- 연출은 2.4초를 넘지 않고, 건너뛸 수 있으며, `disableAnimations`에서는 정지 화면과
  변경 요약 문장으로 대체한다.
- 문구는 성능을 앞세우지 않는다. `새싹 응원이 잎우산으로 자랐어요. 이제 친구까지
  감쌀 수 있어요.`처럼 무엇이 달라졌는지를 먼저 말한다.
- 진화 알림은 하루 최대 2회만 띄우고, 나머지는 캐릭터 상세 화면의 배지로 남긴다.

## 5. 등급과 성능의 관계

### 5.1 문제 정의

상점의 비싼 캐릭터가 값어치를 해야 한다는 요구와, 무료 캐릭터로도 모든 콘텐츠를
완주할 수 있어야 한다는 약속은 정면으로 부딪힌다. 이 문서는 **등급이 성능 총량이
아니라 성능 곡선의 모양을 산다**는 원칙으로 둘을 동시에 만족시킨다.

씨앗은 현금으로 살 수 없으므로 이 구조는 과금 격차가 아니라 **기록한 날 수의 격차**다.
180씨앗짜리 설화를 사려면 대략 12일치 일기가 필요하다. 그 12일이 헛되지 않았다는
감각을 주는 것이 이 설계의 목적이다.

### 5.2 등급이 사는 것과 사지 않는 것

| 등급이 사는 것 | 등급이 사지 않는 것 |
|---|---|
| 레벨에 따른 위력 계수의 **기울기** | 탐험 네 능력치, 지역 상한, 필수 DC |
| 고유 II T3의 **조건 보상 폭** | 하루 XP·씨앗·수집품, 가치 예산 |
| 전용 VFX 시트 제작 수 | 필수 경로 완주 가능성 |
| 전용 대사·관계 beat 수 | 스킬북 장착 슬롯 수, 스킬트리 포인트 |
| 진화 연출 길이 안에서의 표현 밀도 | 파티 인원, 지역 해금, 일일 보상 자격 |

### 5.3 위력 계수 공식

수호전에서만 사용한다. 탐험 판정 계산식은 이 값을 읽지 않는다.

```text
skill_power_scale(level, rarity) = base(rarity) + slope(rarity) * (level - 1) / 29
```

| 등급 | 대표 캐릭터 | 가격 | `base` (Lv1) | `slope` | Lv30 계수 | 무료 등급 대비 |
|---:|---|---:|---:|---:|---:|---|
| 1 | 뽀또 | 0 | 1.00 | 0.20 | 1.20 | 기준 |
| 2 | 로제온, 블루미 | 50 | 0.98 | 0.25 | 1.23 | Lv1 −2% / Lv30 +2.5% |
| 3 | 가시로, 시들잎 | 80·90 | 0.96 | 0.30 | 1.26 | Lv1 −4% / Lv30 +5% |
| 4 | 여우비, 그림싹, 하루 | 120·120·130 | 0.94 | 0.35 | 1.29 | Lv1 −6% / Lv30 +7.5% |
| 5 | 별솔, 설화 | 150·180 | 0.92 | 0.40 | 1.32 | Lv1 −8% / Lv30 +10% |

- 네 등급 모두 무료 등급과 **레벨 13**(줄기 후반, exp 185)에서 정확히 교차한다.
  즉 **신규 사용자가 처음 2주 동안 만나는 구간에서는 무료 캐릭터가 오히려 강하다.**
  비싼 캐릭터는 오래 키운 사람에게만 앞선다.
- 최대 격차 10%는 수호전 라운드 수로 환산하면 약 0.3라운드다. 클리어 여부를 뒤집지
  않고 체감만 만든다.
- 캐릭터 고유 `power`(14~18)는 등급과 무관하게 지금 값을 유지한다. 등급은 계수만
  바꾼다. 즉 값비싼 캐릭터가 처음부터 큰 숫자를 내지는 않는다.

### 5.4 조건 구조

고유 II T3는 품종별 조건을 가진다. 조건은 등급이 높을수록 까다롭고 보상이 크다.

| 등급 | 조건 충족 배수 | 미충족 배수 | 설계 기대 발동률 | 기대값 |
|---:|---:|---:|---:|---:|
| 1 | ×1.00 | ×1.00 | 조건 없음 | 1.000 |
| 2 | ×1.04 | ×0.96 | 0.70 | 1.016 |
| 3 | ×1.07 | ×0.93 | 0.62 | 1.017 |
| 4 | ×1.10 | ×0.90 | 0.56 | 1.012 |
| 5 | ×1.14 | ×0.86 | 0.50 | 1.000 |

기대값이 등급 전체에서 1.00~1.02 안에 들어온다. 다시 말해 **평균적으로는 모두
같고, 잘 쓰면 비싼 캐릭터가 앞선다.** 이 표의 기대 발동률은 콘텐츠 QA에서 실제
로그로 검증하며, ±0.08을 벗어나면 조건 문장을 고치고 배수는 건드리지 않는다.

### 5.5 절대 상한

어떤 레벨·등급·진화·스킬북·의상 조합에서도 다음을 넘지 않는다. 넘으면 CI 실패다.

| 상한 | 값 | 검증 방법 |
|---|---:|---|
| 같은 레벨 계수 상한 — `power_scale × 조건 배수`의 최고/최저 비 | 1.35 | 등급 5 Lv 30 조건 충족 1.505 ÷ 조건 미충족 1.135 = 1.326 |
| 같은 레벨 등급별 **기대** 위력 차 | 10% | 조건 발동률 가중 평균 |
| 기록서 포함 파티 총 위력 — 3인 최대 조합 ÷ 미장착 동일 파티 | 1.60 | 기록서는 계수가 아니라 정액 효과이므로 별도로 잰다 |
| 탐험 유효 능력치 | 10 | 기존 계약 유지 |
| 필수 판정 DC | 13 | 기존 계약 유지 |
| 등급 1 Lv 3 캐릭터 1명 + 길잡이 2명의 전 지역 필수 경로 완주율 | 100% | 10,000 seed 시뮬레이션 |
| 등급 1 Lv 8 파티의 최신 지역 수호전 승률 | 90% 이상 | 10,000 seed 시뮬레이션 |
| 등급별 일일 씨앗·XP 획득 차이 | 0 | 원장 집계 |

## 6. 품종별 고유 스킬 2종 전체 카탈로그

- 어떤 T3도 즉사·즉승·행동 봉쇄를 만들지 않는다. 6라운드 상한과 안전 귀환은 유지된다.

## 7. 마음결 기록서 — 스킬북

### 7.1 기본 계약

- 기록서는 **계정 귀속 영구 라이선스**다. 소모되지 않고, 파괴되지 않으며, 강화·합성·
  분해가 없다. 의상과 같은 취급이다.
- 같은 코드의 기록서는 계정에 한 장이다. 따라서 한 파티에서 두 캐릭터가 같은 책을
  동시에 장착할 수 없다. 장착 변경은 run 밖에서 무료·무제한이다.
- 모든 기록서는 `reward_affecting: false`다. XP·씨앗·수집품 수량·가치 예산·확보 슬롯

일기 목표의 부가 보상이며 거래·구매·변환할 수 없다.

## 9. 수호자 스케일링

### 9.1 성장을 상쇄하지 않는다

파티가 강해진 만큼 적도 강해지면 성장한 이유가 사라진다. 반대로 적이 전혀 안 따라오면
후반 지역이 무의미해진다. 몽그루는 **적이 파티 성장의 60%만 따라온다**는 규칙을 쓴다.

```text
G = 파티 실제 소유 대원의 평균 성장지수 (0~100)
성장지수 = round((level - 1) / 29 * 100)
길잡이는 G 계산에서 제외한다. 전원이 길잡이면 G = 0이다.

guardian_barrier = base_barrier * (1 + 0.18 * G / 100)
guardian_power   = 콘텐츠 고정값. G를 읽지 않는다.
```

| 파티 구성 | 평균 레벨 | G | 파티 위력 지수 | 장벽 배수 | 순 우위 | 예상 라운드 | 전멸률 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 등급 1 Lv 5 1명 + 길잡이 2 | 5 | 14 | 100 | 1.025 | 1.00 | 5.4 | 7% |
| 등급 2~3 Lv 16 2명 + 길잡이 1 | 16 | 52 | 138 | 1.094 | 1.29 | 4.3 | 2% |
| 등급 4~5 Lv 28 3명, `B1`·`B2` 장착, T3 | 28 | 93 | 196 | 1.167 | 1.72 | 3.4 | 0.4% |

라운드 수는 순 우위의 정확한 역수가 아니다. 1라운드는 집중력을 만드는 데 대부분
쓰이고 라운드는 정수로만 끝나므로, 우위가 커질수록 감소 폭이 완만해진다. 위 표의
라운드 값은 이 두 효과를 반영한 시뮬레이션 중앙값이며 16.4의 합격선으로 검증한다.

- 적 위력은 성장을 읽지 않으므로 HP 상승이 그대로 안전 마진이 된다. 오래 키운 파티가
  전멸할 걱정 없이 지휘에 집중할 수 있다.
- 최대 성장 파티도 라운드가 3.4 밑으로 내려가지 않는다. 전투가 한 번의 클릭으로
  끝나 버리면 수동 지휘의 재미가 사라지기 때문이다. 장벽 배수 하한 1.0, 상한 1.18을
  둔다.
- 6라운드 상한과 긴급 귀환 규칙은 그대로다. 실패해도 캐릭터는 손실·퇴화하지 않는다.

### 9.2 체감 성장의 진짜 출처

숫자 배수는 전체 체감의 일부다. 실제로 "강해졌다"고 느끼게 하는 것은 다음 순서다.

1. 명령 선택지가 2개(공격·방어)에서 5개(공격·방어·고유 II·기록서 2)로 늘어난다.
2. HP 3 → 6으로 한 번 맞아도 되는 여유가 생긴다.
3. 시작 집중력 3 → 4로 첫 라운드부터 스킬을 쓸 수 있다.
4. 고유 스킬의 이름·연출·범위가 두 번 바뀐다.
5. 그 결과로 장벽이 눈에 띄게 빨리 깎인다.

## 10. 연출과 이펙트 계약

### 10.1 등급은 화려함을 사지 않는다

기존 계약(`14.3`)의 "스킬 효과의 강약을 희귀도 색·화면 흔들림·과도한 섬광으로
표현하지 않는다"를 유지한다. 등급이 사는 것은 **전용 제작량**이다.

| 등급 | VFX 구성 | 전용 시트 | 진화 시 |

| 1~2 | 공명 공용 시트 + 품종 accent 오버레이 | 0 | T3에서 accent 색·궤적 변형 |

| 4 | 품종 전용 시트 1장 + 조건 충족 전용 변형 | 2 | T3 전용 마무리 프레임 |
| 5 | 품종 전용 시트 1장 + 조건 변형 + T3 전용 시트 | 3 | T3 전용 8프레임 시트 |

공통 예산은 등급과 무관하게 동일하다. 재생 300~500ms, 캐릭터 bbox 바깥 12px 이내,
동시 파티클 최대 12개, 화면 흔들림 2.8~3.5px 단일 구간. 5등급이라고 더 길거나 더
밝게 만들지 않는다. 대신 별솔의 프리즘은 정말 프리즘답게, 설화의 서리는 정말
서리답게 그려진다. 이것이 "캐릭터에 알맞은 느낌"의 정의다.

### 10.3 접근성

- 모든 진화·조건 충족은 색만으로 구분하지 않는다. 아이콘·텍스트·숫자를 같이 쓴다.
- 조건 충족 여부는 명령 확정 **전에** 문장으로 보여 준다. `약점과 공명이 같아
  그림자 서약이 켜져요`처럼 원인을 함께 읽는다.
- 스크린리더는 슬롯 4개를 `고유·길`, `고유·수호`, `기록서 1`, `기록서 2` 순으로
  읽고 각 항목의 tier와 사용 가능 여부를 함께 읽는다.
- `disableAnimations`에서는 진화·조건 연출을 정지 화면과 live region 문장으로 대체한다.
- 조작 표적 최소 48dp, 320px 폭·200% 글자에서 4슬롯이 2×2로 접힌다.

## 11. 데이터 모델

### 11.1 파생 값 — 테이블을 만들지 않는 것

`level`, `maturity`, `signature_tier`, `skill_power_scale`, `growth_index`는 전부 exp와
품종 등급에서 계산하는 파생 값이다. 테이블에 저장하지 않고 도메인 함수로만 계산해
서버와 앱이 같은 값을 보게 한다. 저장하면 exp 보정·마이그레이션마다 불일치가 생긴다.

```text
level_from_exp(exp) -> 1..30
maturity(level) -> 0 | 1
signature_tier(stage, level) -> 1 | 2 | 3
skill_power_scale(level, rarity) -> float
growth_index(level) -> 0..100
```

단, 수확 시점 값은 스냅샷으로 고정해야 하므로 `plants.final_level`을 추가한다.

### 12.3 탐험·전투 요청 확장

- 탐험 문맥 행동은 기존 요청에 선택 필드 `skill_book_code`를 더한다. `skill_node_code`와
  동시에 보내면 422다. 한 확정 행동에는 하나만 쓴다.
- 수호전은 기존 `POST /expeditions/{run_id}/combat/turns`의 `action: skill`에
  `skill_code`를 함께 받는다. 생략하면 고유 II로 간주해 구버전 클라이언트와 호환된다.
- 잘못된 code, 미장착 책, 사용 횟수 소진, 조건 미충족, 순서상 집중력 부족은 전부 422다.
- 시작한 run은 `skill_book_snapshot`을 따르며 도중 장착 변경은 반영하지 않는다.

## 13. UI 계약

### 13.1 캐릭터 스킬 화면

- 4슬롯을 2×2 카드로 배치한다. 위 두 칸이 고유, 아래 두 칸이 기록서다.
- 각 카드에 이름, tier 표식(잎눈 1~3개), 사용 횟수, 유효 상황 한 줄을 표시한다.
- 하단에 레벨 바와 `다음: 레벨 23에 두 번째 기록서` 한 줄을 둔다. 남은 exp 숫자를
  카운트다운으로 압박하지 않는다.
- 기록서 카드를 누르면 보유 목록이 열리고, 미보유 항목은 획득 조건을 그대로 보여 준다.
  잠긴 항목을 흐리게 처리하되 구매 유도 배지를 붙이지 않는다.

### 13.2 파티 준비 화면

- 3인 각각의 4슬롯 요약을 한 줄로 보여 주고 `stack_group` 충돌을 미리 경고한다.
- 같은 기록서를 두 명에게 배정하려 하면 확정 전에 막고 이유를 문장으로 설명한다.
- 추천 정렬은 지금처럼 최근 선두 횟수가 적은 식물을 먼저 제안한다. 등급이나 레벨이
  높은 캐릭터를 위로 올리지 않는다.

### 13.3 상점

- `기록서` 탭을 신설한다. 캐릭터·의상·꾸미기 탭과 섞지 않는다.
- 가격, 효과, 장착 가능 슬롯, 유효 상황을 구매 전에 전부 공개한다.
- 성능 비교 문구(`가장 강한`, `필수`)를 쓰지 않는다. 효과를 그대로 적는다.
- 미보유 캐릭터의 T3 효과도 상점에서 미리 읽을 수 있다. 사기 전에 알 수 있어야 한다.

### 13.4 수호전

- `스킬` 버튼을 누르면 고유 II와 전투형 기록서가 최대 3항목으로 열린다.
- 각 항목에 예상 장벽 피해, 집중력 비용, 조건 충족 여부를 확정 전에 표시한다.
- 조건이 꺼져 있으면 그 이유를 한 줄로 읽는다. 조건을 켤 방법도 함께 알려 준다.

## 14. 밸런스 운영

### 14.1 지표와 경보선

기존 `9.13`의 지표를 유지하고 다음을 추가한다. 식물 ID는 분석용 난수 키로 치환하고
일기 본문·감정 점수는 집계하지 않는다.

| 지표 | 경보선 | 조치 |
|---|---:|---|
| 등급별 수호전 평균 라운드 편차 | 0.4라운드 초과 | 조건 문장·유효 장면 먼저 조정. 계수는 마지막 |
| 단일 기록서 장착률 (같은 등급·슬롯 내) | 35% 초과 | 인기 책 하향 금지. 다른 책의 유효 사건 보강 |
| 미장착 캐릭터 비율 | `B1` 해금자 중 40% 초과 | 획득 안내와 첫 무료 지급 검토 |
| 등급 5 보유자와 미보유자의 최신 지역 완주율 차 | 10%p 초과 | 조건 난도 완화 |
| 등급 1 Lv 8 파티 수호전 승률 | 90% 미만 | 즉시 배포 중단 |
| T3 조건 실제 발동률 | 설계값 ±0.08 초과 | 조건 문장 수정. 배수 변경 금지 |
| 기록서 구매 후 7일 내 미장착률 | 30% 초과 | 설명·추천 문구 개선 |
| 등급별 일일 씨앗 획득 차 | 0 초과 | 즉시 배포 중단 |
| 진화 알림 하루 노출 | 2회 초과 | 알림 정책 버그 |

### 14.2 조정 우선순위

밸런스가 어긋났을 때 **아래 순서를 지킨다.** 인기 있는 것을 깎는 것이 가장 마지막이다.

1. 그 스킬이 쓸모없어 보이는 **사건·장면을 추가**한다.
2. **조건 문장**을 고쳐 발동률을 설계값으로 되돌린다.
3. 약한 쪽의 **적용 대상·타이밍**을 넓힌다.
4. 그래도 안 되면 **계수를 조정**한다.
5. 하향은 위 넷이 모두 실패했고, 상한(5.5)을 실제로 넘었을 때만 한다.

어떤 캐릭터의 사용률이 높다는 이유만으로 그 캐릭터를 하향하지 않는다. 이것은 기존
`9.13`의 규칙이며 이 문서에서도 그대로 유지한다.

### 14.3 하향 시 사용자 보호

- `nerf` 또는 `rework`는 배포 **7일 전에 예고**하고 변경 이유를 함께 공개한다.
- 배포 후 7일간 해당 기록서를 **씨앗 전액 환불**할 수 있다. 환불하면 보유에서 빠지고
  장착 슬롯은 비워진다. 환불 창이 지나면 보유는 유지되고 환불만 닫힌다.
- 영향받은 캐릭터의 스킬 배분·장착은 무료로 다시 할 수 있다.
- 진행 중 run과 journey는 스냅샷을 유지한다. 시작한 판이 도중에 약해지지 않는다.
- 이미 얻은 3등급 기록서를 회수하지 않는다. `is_active=false`로 신규 획득만 닫는다.

|---|---|
| 6주 pack | 기록서 4종, 품종 1종 전용 진화 연출, 기존 지역 사건 4개, 밸런스 조정 |
| 2주 hotfix 창 | 경보선을 넘은 지표에 한해 조건 문장·유효 장면만 수정 |
| 분기 리포트 | 지표 요약과 변경 이유를 사용자에게 공개. 개별 사용자 데이터는 포함하지 않음 |

새 지역을 추가할 때만 기록서를 추가하지 않는다. 기존 네 지역에도 같은 양의 새 사건과
새 기록서 유효 장면을 역류시켜, 초기 지역과 초기 캐릭터가 계속 현재 콘텐츠에 남게 한다.

## 15. 콘텐츠 validator

콘텐츠 팩 CI가 다음을 강제한다. 하나라도 실패하면 배포하지 않는다.

- 모든 기록서가 닫힌 `effect_module` 하나, 단일 `stack_group`, `effect_budget` 1~2를
  가진다. 두 효과를 한 책에 넣은 항목이 0건이다.
- 모든 기록서의 `reward_affecting`이 `false`이고, XP·씨앗·수집품 수량·가치 예산·확보
  슬롯 칸 수를 참조하는 코드 경로가 없다.
- 3등급 기록서 8종 모두 반대급부 필드가 비어 있지 않다.
- 모든 기록서가 네 지역 중 최소 3곳, 지역당 사건 2개 이상에서 유효한 target을 가진다.
- 고유 I의 T2 효과 중 수치가 오른 항목이 0건이다.
- 고유 II의 T2 부가 효과가 예산 목록(방어 1, 회복 1, 집중력 1, 피해 +4) 밖의 값을
  쓰지 않는다.
- T3 조건이 전부 관찰 가능한 전투 상태이며 숨은 확률을 포함하지 않는다.
- 탐험 능력치 계산 경로에 `rarity`, `power_scale`, `skill_book` 인자가 들어가지 않는다.
- 해금 조건 8종과 최초 달성 8종의 조건이 전부 UI에 사전 공개된다.
- 세 획득 경로의 종수 합이 카탈로그 총 종수와 일치한다. 어느 경로로도 얻을 수 없는
  기록서가 0건이다.
- 새 기록서가 기존 기록서와 같은 상황에서 완전 상위 호환이 아니다.

## 16. 테스트 계약

### 16.1 서버 unit / property

- `level_from_exp`가 stage 경계와 어긋나지 않는다. 30레벨 전 구간 경계 테스트.
- `FORM_STAT_MODIFIERS` 합이 여섯 성장형 모두 4다. 기존 불변식 테스트 유지.
- `maturity` 적용 후에도 `effective_stat <= 지역 상한`이 모든 stage·레벨·성장형·
  지역 조합에서 성립한다.
- 같은 레벨에서 `power_scale × 조건 배수`의 최고/최저 비가 1.35 이하다. 다섯 등급 ×
  30레벨 × 조건 충족·미충족 전수 계산.
- 기록서를 포함한 3인 파티 최대 조합이 미장착 동일 파티의 1.60배를 넘지 않는다.
  `ringcount_record` × `shadow_oath` × 1등급 정액 보너스까지 함께 계산한다.
- 등급별 기대 위력 차가 10% 이하다.
- 기록서 장착 검증이 등급·슬롯·중복·소유권을 모두 거절한다.
- 중복 구매가 씨앗을 차감하지 않는다.

### 16.2 서버 integration

- 등급 1 Lv 3 캐릭터 1명 + 길잡이 2명이 네 지역 필수 경로를 10,000 seed 전부 완주한다.
- 등급 1 Lv 8 파티가 관측실 수호자를 90% 이상 승리한다.
- 기록서를 한 권도 장착하지 않은 파티가 모든 지역 수호전을 승리할 수 있다.
- 진행 중 run이 `content_version` 변경에 영향받지 않는다.
- 환불이 보유·장착·씨앗 잔액을 한 트랜잭션에서 되돌린다.
- 회향 각인이 stage·`final_form`·박물관 스냅샷을 바꾸지 않는다.
- 등급별 일일 씨앗·XP 원장 합계가 완전히 같다.

### 16.3 Flutter widget

- 4슬롯 카드가 320px 폭·200% 글자에서 2×2로 접히고 잘리지 않는다.
- 잠긴 슬롯이 사유 문구와 함께 노출되고 스크린리더가 읽는다.
- 수호전 스킬 목록이 최대 3항목이며 조건 상태를 확정 전에 표시한다.
- 진화 연출이 건너뛰기 가능하고 `disableAnimations`에서 정지 화면으로 대체된다.
- 상점 기록서 탭이 미보유 항목의 획득 조건을 그대로 보여 준다.

### 16.4 시뮬레이션

10품종 × 5등급 대표 × 6레벨 구간(3, 8, 16, 23, 27, 30) × 4지역 × 3난이도 조합에
대해 10,000 seed를 실행하고 다음을 기록한다.

| 지표 | 합격선 |
|---|---:|
| 필수 경로 완주율 | 모든 조합 100% |
| 수호전 승률 | 모든 조합 90% 이상 |
| 등급별 평균 라운드 편차 | 0.4 이내 |
| 레벨 3 → 30 평균 라운드 감소 | 1.5~2.2 |
| 특정 기록서가 유일한 최적해인 상황 | 0건 |
| 특정 등급 없이는 불가능한 필수 경로 | 0건 |

## 17. 구현 마일스톤

| 단계 | 범위 | 완료 기준 |
|---:|---|---|
| M1 | `level_from_exp`, `maturity`, `growth_index` 도메인 함수와 API 노출 | 기존 탐험 완주율·시뮬레이션 회귀 0 |
| M2 | 고유 I·II의 T2·T3 진화, 홈 진화 연출, `signature_tier` 스냅샷 | 진화 전후 시뮬레이션이 16.4 합격선 통과 |
| M3 | 4슬롯 UI, `plant_skill_loadouts`, 1등급 기록서 14종, 상점 탭 | 미장착 파티 완주율 100% |
| M4 | 2등급 14종(상점 6·해금 8), `power_scale` 등급 계수, 수호자 장벽 스케일 | 등급별 편차 0.4 이내 |
| M5 | 3등급 8종, 숙련 기록, 회향 각인, 밸런스 원장·환불 창, 분기 리포트 | 15·16장 전 항목 통과 |

M1~M2는 기존 데이터만 읽으므로 마이그레이션이 없다. M3부터 신규 테이블 3개를 추가하고,
기존 사용자에게는 `B1`·`B2`가 비어 있는 기본 상태로 열린다. 기존 스킬트리 배분과
`plant_expedition_skill_builds`는 그대로 유지되며 이 문서의 슬롯과 독립이다.

## 18. 금지하는 지름길

- 레벨을 저장 컬럼으로 만들어 exp와 따로 관리하는 것
- 등급 인자를 탐험 능력치 계산식에 넣는 것
- 기록서에 XP·씨앗 배율을 붙여 "체감"을 만드는 것
- 확률형 기록서 상자, 중복 지급 후 합성, 강화 실패
- 인기 캐릭터를 사용률만 보고 하향하는 것
- 3등급 기록서를 나중에 상점에서 판매하는 것
- 진화·조건 발동을 숨은 확률로 처리하는 것
- 새 지역에서만 기록서를 공급해 초기 지역을 유물로 만드는 것
- 진화 연출을 등급별로 길게 만들어 5등급을 화려함으로 광고하는 것
- 슬롯 해금을 씨앗이나 유료 상품으로 앞당기는 것

## 부록 A. 기준 성장 시나리오

### A.1 1일차 — 무료 스타터 뽀또

50자 일기를 쓰고 exp 40을 받는다. 레벨 4, stage 2 새싹. 탐험이 열리고 고유 I
`새싹 응원`과 고유 II `포근한 싸개잎`을 T1으로 쓴다. 기록서 슬롯은 잠겨 있고, 잠금
카드는 `줄기가 되면 기록서를 한 권 챙길 수 있어요`라고 읽는다. 기억서고 수호전에서
길잡이 둘과 함께 5라운드에 승리한다.

### A.2 6일차 — 첫 기록서

exp 105로 레벨 9, stage 3 줄기. `B1` 슬롯이 열린다. 엿새 동안 모은 씨앗 약 120 중 80으로 1등급
`또렷한 겨냥`과 `조용한 심호흡`을 사고 상황에 따라 바꿔 낀다. 기억서고 최초 완주로
2등급 `뿌리 지도법`이 무료로 서고에 들어온다. 수호전 라운드가 5.4에서 4.9로 줄고
"뭘 낄지"라는 새 판단이 생긴다.

### A.3 3주차 — 첫 진화와 두 번째 캐릭터

exp 260으로 레벨 16, stage 4 개화. 홈에서 진화 연출이 재생되고 `새싹 응원`이
`잎우산`이 된다. 이제 친구의 준비도 손실도 막을 수 있다. 수호전 고유 II에 자신
방어 +1이 붙는다. 그동안 모은 씨앗 400 중 120으로 4등급 그림싹을 해금한다. 그림싹은
지금 레벨 3이라 뽀또보다 약하지만, 오래 키우면 앞선다는 설명이 상점에 그대로 적혀 있다.

### A.4 6주차 — 만개와 두 번째 슬롯

exp 460으로 레벨 23, stage 5 만개. `B2`가 열린다. 기억서고 깊은 조사를 처음 완주해
3등급 `뿌리 사서의 색인`을 얻고 `B2`에 끼운다. 지도 전체 노드 종류가 보이는 대신 숨은
간선은 스스로 찾아야 한다. 수확할 수도 있지만 레벨 30까지 키우기로 한다. 두 선택 모두
씨앗·XP 차이가 없다.

### A.5 9주차 — 레벨 30

exp 900. 고유 스킬이 T3가 되고 수호전 HP가 6, 시작 집중력이 4가 된다. 등급 1 뽀또의
위력 계수는 1.20이다. 같은 레벨의 5등급 설화는 1.32이고 조건을 맞추면 1.50이지만,
조건을 놓치면 1.13으로 뽀또보다 낮다. 파티 평균 성장지수 100에서 장벽은 18%만
두꺼워졌으므로 수호전은 3.4라운드에 끝난다. 첫 판의 5.4라운드와 비교해 확실히 강해졌고,
그 사이에 아무도 무언가를 잃지 않았다.
