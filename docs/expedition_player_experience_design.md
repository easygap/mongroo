# 몽그루 직접 탐험 플레이어 경험 설계서

최종 갱신: 2026-08-04
상태: 사용자 경험 구현 기준 확정안
대상 버전: `interactive-expedition-player-experience-v1.0`
상위 규칙: `docs/interactive_adventure_design.md`
연결 규격: `docs/expedition_skill_tree_catalog.md`,
`design-system/EXPEDITION_ASSET_PRODUCTION.md`

이 문서는 탐험이 기술적으로 동작하는지를 넘어, 사용자가 실제로 플레이했을 때
`내가 키운 캐릭터와 함께 길을 골랐다`, `내 선택 때문에 다른 장면이 생겼다`, `보상 없이도
한 번 더 가 보고 싶다`고 느끼게 만드는 경험 계약이다. 구현 편의보다 플레이어가 보고,
이해하고, 선택하고, 기억하는 순서를 우선한다.

“100점”은 모든 사람에게 취향상 만점을 강요한다는 뜻이 아니다. 출시팀이 통제할 수 있는
경험 요소를 빠짐없이 설계하고, 서로 다른 사용자군의 실제 플레이에서 정해진 합격선을
모두 통과했다는 뜻이다. 테스트하지 않은 재미를 문서만으로 100점이라 부르지 않는다.

## 0. 한 문장 약속

> 마음 일기로 애지중지 키운 캐릭터들과 직접 길을 고르고, 서로의 성격으로 문제를 풀며,
> 함께 만든 모험을 집으로 가져오는 8~15분의 따뜻한 탐험.

다음 다섯 감정이 한 판 안에 순서대로 생겨야 한다.

1. `기대`: 오늘 누구와 어디로 갈지 스스로 고른다.
2. `호기심`: 안개 너머에 무엇이 있는지 알고 싶다.
3. `주도감`: 정보와 대가를 이해한 뒤 길·행동자·해결법을 선택한다.
4. `애착`: 선택한 캐릭터의 성격과 성장형이 동작·표정·대사로 답한다.
5. `여운`: 보상보다 먼저 함께한 장면과 다음에 이어질 단서를 기억한다.

이 중 하나라도 반복해서 빠지면 기능은 완성돼도 플레이어 경험은 미완성이다.

## 1. 플레이어 가치와 금지선

### 1.1 플레이어에게 주는 세 가지 가치

| 가치 | 플레이 중 증거 | 플레이 뒤 증거 |
|---|---|---|
| 함께했다 | 모든 소유 파티원이 출발·활약 기회·귀환에 등장 | 홈 대사와 기록에 행동자·장소가 남음 |
| 내가 골랐다 | 경로·비용·예상 결과를 보고 확정 | 결과 카드가 선택과 열린/닫힌 길을 연결해 설명 |
| 다시 가면 다르다 | 지역 서사 실마리, 사건, 파티 관계가 달라짐 | 미발견 실마리와 다른 조합의 가능성이 보임 |

### 1.2 플레이어 경험 금지선

- 보상을 받으려면 재미없는 방을 전부 눌러야 하는 체크리스트를 만들지 않는다.
- `추천`을 사실상의 정답 파티, 자동 편성, 전투력 순위로 바꾸지 않는다.
- 모르는 정보를 숨겨 놓고 선택 뒤에만 큰 손해를 공개하지 않는다.
- 안전 귀환을 실패 화면, 붉은 경고, 캐릭터 실망 대사로 표현하지 않는다.
- 캐릭터를 데려왔는데 한마디·한 동작·한 해결 기회도 없이 끝나는 run을 만들지 않는다.
- 이미 본 문장을 새 콘텐츠처럼 색만 바꿔 반복하지 않는다.
- 연출을 보기 위해 입력을 기다리게 하거나 skip 사용자에게 보상을 늦게 주지 않는다.
- 일기 감정과 탐험의 위험·성공·보상·대사 어조를 직접 연결하지 않는다.
- 연속 출석, 만료 입장권, 시즌 삭제, 캐릭터 피로도로 다시 접속하게 만들지 않는다.
- 재미 지표가 낮을 때 XP·씨앗·희귀 확률을 올려 체류를 사지 않는다.

## 2. 대상 사용자와 모두를 위한 성공 조건

한 가지 플레이 습관만 표준 사용자로 두지 않는다.

| 사용자 유형 | 원하는 것 | 반드시 제공 | 강요하지 않는 것 |
|---|---|---|---|
| 일기 중심 | 오늘 마음을 쓰고 캐릭터 반응을 봄 | 일기 직후 1탭으로 탐험 준비, 대표 캐릭터의 연결 대사 | 매일 탐험 완주 |
| 애착 중심 | 좋아하는 한두 캐릭터와 계속 함께함 | 오래된 캐릭터의 개인 기록·관계 변화 | 새 캐릭터 강제 출전 |
| 수집 중심 | 여러 캐릭터·의상·장면을 모음 | 미발견 단서와 획득 경로의 명확한 안내 | 기간 한정·무작위 획득 |
| 탐색 중심 | 지도를 읽고 다른 길을 찾음 | 숨은 길·되돌아가기·선택 목표 | 보상 효율 하나로 수렴하는 경로 |
| 짧은 이용 | 3~5분만 쓸 수 있음 | 자동 저장, 야영지 중단, 자동 순찰 | 완료 전 손실 또는 만료 |
| 접근성 이용 | 시각·청각·운동·인지 보조가 필요 | 목록 지도, 읽기 순서, 대체 신호, 느린 확인 | 실시간 타이밍 판정 |

어떤 유형도 필수 경로에서 열등한 보상이나 낮은 성공률을 받지 않는다. 차이는 플레이
방식·발견 장면·기록의 모양에만 둔다.

## 3. 세션 구조

### 3.1 사용 가능한 시간에 따른 진입점

| 사용 가능 시간 | 대표 행동 | 종료 상태 | 다음 접속 연결 |
|---:|---|---|---|
| 1~3분 | 일기 확인, 파티 후보 보기, 순찰 보내기, 기록 읽기 | 즉시 완료 | 홈에 오늘 공명과 이어하기 표시 |
| 3~5분 | 직접 탐험 2~3노드 진행 | 행동 단위 저장 후 중단 | 현재 방과 마지막 선택 한 줄 요약 |
| 8~15분 | 일반 직접 탐험 완주 | 귀환·기록·보상 | 홈에 귀환 반응과 다음 실마리 |
| 20~35분 | 장거리 개척 2~3구간 | 야영지 저장 또는 전체 귀환 | 원정 띠와 사용한 조 복구 |

앱은 사용자가 남은 시간을 입력하게 하지 않는다. `예상 8~12분`, `다음 야영지까지
약 4분`처럼 선택 직전에만 알려 준다. 시간 범위는 17장의 playtest에서 측정한 지역별
중앙값과 25~75 percentile로 콘텐츠 pack에 고정하고, 개인 행동을 추적해 압박하는
countdown으로 바꾸지 않는다.

### 3.2 한 판의 감정 리듬

| 구간 | 목표 시간 | 경험 | 시스템 역할 |
|---|---:|---|---|
| 출발 | 0:00~0:45 | 기대·준비 | 파티 한 줄 반응, 목표 실마리, 첫 분기 미리보기 |
| 발견 | 0:45~3:00 | 호기심 | 쉬운 사건 1, 지역 장치 소개, 첫 캐릭터 활약 기회 |
| 확장 | 3:00~7:00 | 주도감 | 의미 있는 분기 2, 숨은 길/선택 발견, 자원 선택 |
| 긴장 | 7:00~10:00 | 집중 | 수호자 또는 연쇄 사건, 두 번째·세 번째 활약 기회 |
| 해소 | 10:00~12:00 | 성취 | 목표 발견, 계속 탐색/빠른 귀환 결정 |
| 귀환 | 12:00~13:00 | 애착·여운 | 동작, 대사, 선택의 흔적, 보상, 다음 실마리 |

사건이 연속 3개 나오거나, 텍스트를 읽지 않는 단순 이동이 4회 연속 나오거나, 90초
안에 새 정보·결정·캐릭터 반응 중 아무것도 없으면 pacing validator가 실패한다.

### 3.3 중단과 복귀

- 모든 확정 행동 뒤 1초 안에 `저장됨`을 짧게 표시한다.
- 허브로 나가기는 언제나 진행을 유지하며 별도 재화나 확인 문구로 겁주지 않는다.
- 복귀 카드에는 `어디`, `누구와`, `마지막으로 무엇을 했는지`, `다음 행동까지 예상 시간`
  네 가지만 보여 준다.
- 24시간 이상 뒤 복귀하면 2문장 요약을 먼저 보여 주고 지도를 연다. 24시간 미만이면
  바로 현재 방으로 간다.
- 콘텐츠 버전이 바뀌어도 진행 run의 문장·지도·스킬은 snapshot 버전으로 끝낸다.

## 4. 첫 30분 경험

### 4.1 탐험 해금 순간

stage 2 도달 연출이 끝난 뒤 홈에서 캐릭터가 기억서고 쪽의 작은 빛을 발견한다. 전면
팝업으로 다른 기능을 가리지 않고 캐릭터 옆 `같이 가 볼까?` 말풍선을 누르면 시작한다.
`나중에`를 누르면 홈의 탐험 카드에만 표시하고 매 접속마다 다시 띄우지 않는다.

첫 탐험은 일기 보상 자격과 무관하게 `tutorial`로 무료이며, 완료 보상은 고정된 작은
꾸미기 1개와 발견 장면뿐이다. 일기를 쓰지 않았다는 이유로 핵심 조작 학습을 막지 않는다.

### 4.2 첫 튜토리얼 6단계

| 단계 | 화면에 처음 보이는 것 | 사용자가 하는 것 | 가르치지 않는 것 |
|---|---|---|---|
| 1 출발 | 활성 캐릭터+길잡이 1명, 지역·시간 | 그대로 시작 또는 길잡이 확인 | stat cap, 트리 편집 |
| 2 첫 길 | 연결된 방 2개와 종류·비용 | 방 탭→미리보기→이동 | 숨은 길, 난이도 |
| 3 첫 사건 | 두 능력치 선택과 안전 선택 | 행동자와 선택을 고름 | 세부 점수식 전체 |
| 4 첫 스킬 | 현재 상황에 맞는 고유 스킬 1개 강조 | 사용 또는 `그냥 해결` | 성장형·트리 조합 |
| 5 갈림길 | 목표 방향과 선택 발견 방향 | 원하는 길을 고르고 무료 되돌아감 | 최적 경로 평가 |
| 6 귀환 | 목표 발견, 계속/귀환 | 빠른 귀환 후 결과 확인 | 연구·장거리 전체 설명 |

코치 마크는 한 화면에 하나, 2문장 이하, 사용자가 조작할 실제 요소 옆에 붙인다. 이미
정답 행동을 한 사용자는 설명을 자동 건너뛴다. 도움말은 다시 열 수 있고, 튜토리얼은
설정에서 언제든 재생할 수 있다.

### 4.3 첫 탐험의 성공 기준

- 사용자가 도움 없이 `안개`, `길빛`, `준비도`, `안전 선택`, `빠른 귀환`을 자기 말로
  설명할 수 있다.
- 첫 사건 전에 숫자를 5개 넘게 동시에 보여 주지 않는다.
- 첫 캐릭터 스킬은 썼을 때 즉시 경로 또는 선택 결과가 달라져야 한다.
- 최소 한 번 `길이 달라도 틀린 선택이 아니다`라는 결과를 경험한다.
- 결과 화면에서 보상보다 자기 캐릭터가 무엇을 했는지 먼저 기억한다.
- 튜토리얼 완료 뒤 바로 두 번째 탐험을 권하지 않고 `홈으로 돌아가 쉬기`를 기본 버튼으로
  둔다.

## 5. 첫 7일과 첫 30일의 발견 순서

달력 출석이 아니라 사용자가 완료한 `경험 이정표` 순서로 연다. 하루에 몰아서 해도
경제 보상은 늘지 않고, 며칠 쉬어도 잃는 항목이 없다.

| 이정표 | 새로 보여 주는 것 | 사용자에게 남는 것 |
|---:|---|---|
| 첫 완주 | 이동·사건·스킬·귀환 | 첫 원정 사진, 캐릭터 역할 기록 |
| 두 번째 완주 | 다른 template와 선택 발견 | `같은 지역도 길이 달라져요` 이해 |
| 서로 다른 조 2회 | 파티 관계 대사 | 두 캐릭터의 첫 관계 기억 |
| stage 3 캐릭터 등장 | 1포인트 트리, 세 선택 중 하나 | 성장으로 플레이 방식이 변한다는 감각 |
| 기억서고 3 template | 지역 지식과 미발견 서사 실마리 | 과거 지역 완성 목표 |
| 우물정원 최초 진입 | 순서·소리 장치 | 거리가 멀수록 규칙이 깊어진다는 감각 |
| 첫 안전 귀환 | 발견 보존과 재도전 자격 | 실패 공포 없이 스스로 멈출 수 있다는 신뢰 |
| 첫 수확 캐릭터 재출전 | 수확 뒤에도 남은 유대·의상 | 캐릭터가 관상용으로 끝나지 않음 |
| 장거리 최초 완주 | 구간별 다른 조와 원정 띠 | 여러 캐릭터가 한 모험을 나눠 맡음 |

첫 7개 이정표까지 한 번에 노출하는 메뉴는 최대 3개다. 아직 먼 기능은 자물쇠 목록 대신
세계 안의 실루엣과 한 줄 단서로만 보여 준다. 첫 30일 안에 모든 콘텐츠를 소진하게 만드는
출석 보상은 만들지 않는다.

## 6. 한 번의 선택이 재미있어지는 계약

### 6.1 선택 카드의 정보 순서

모든 선택은 다음 순서로 읽힌다.

1. `무엇을 한다`: 캐릭터 말투가 아닌 명확한 행동 label
2. `누가 한다`: 행동자 초상·이름·사용할 능력치
3. `무엇을 쓴다`: 길빛·준비도·스킬 횟수
4. `무엇이 예상된다`: 정확한 결과 단계와 경로 변화
5. `왜 다른가`: 다른 선택과 구별되는 한 줄 설명

예시:

```text
남은 잉크 자국을 잇는다
여우비 · 관찰 7 + 지원 2 = 9 / 기준 10
예상: 우회 · 준비도 1 · 서쪽 문이 열려요
[미리 살피기 사용] 예상: 해결 · 준비도 소비 없음
```

`성공 확률 높음`, `추천`, 색상만 다른 화살표는 정확한 설명을 대신할 수 없다.

### 6.2 의미 있는 선택의 판정

두 선택이 의미 있게 다르려면 아래 네 항목 중 최소 둘이 달라야 한다.

- 다음에 열리는 길 또는 지도 정보
- 행동하는 캐릭터와 그 캐릭터의 반응
- 길빛·준비도·스킬 중 하나의 소비
- 남는 이야기·관계·발견 기록

결과 문장만 다르고 상태·경로·행동자가 같은 선택은 하나로 합친다. 경제 보상 수량만
다른 선택도 허용하지 않는다.

### 6.3 확정과 실수 방지

- 방 이동은 탭으로 미리보고 `이동`으로 확정한다.
- 사건 선택은 카드 탭 후 예상 결과가 펼쳐지고 같은 위치의 `이 선택으로`로 확정한다.
- 자원 2 이상 또는 마지막 스킬을 쓰는 행동만 짧은 추가 확인을 표시한다.
- 확정 전에는 비용이 변하지 않으며 확정 뒤에는 애니메이션 중 버튼을 잠근다.
- 이미 방문한 방으로 돌아가기는 확인 없이 즉시 이동하고 비용이 없다.
- 선택 결과는 되돌리지 않지만 앱 종료·네트워크 끊김을 선택 변경으로 취급하지 않는다.

## 7. 지도가 진짜 탐험처럼 느껴지는 조건

### 7.1 공간 기억

- 각 template에는 입구 외에 색·형태·소리로 구별되는 landmark 2개가 있다.
- 미방문 노드는 방향과 흐릿한 실루엣만 보이고, 방문 뒤 이름·사건 흔적이 남는다.
- 사용자가 연 길, 일부러 지나친 길, 안전 우회한 길의 선 모양이 서로 다르다.
- 지도 확대율·중심은 앱을 나갔다 돌아와도 유지한다.
- 목록 지도에서도 같은 landmark·방향·연결·방문 흔적을 같은 순서로 읽는다.

### 7.2 자유도의 최소 단위

모든 일반 run은 다음을 실제로 제공한다.

- 목표까지 비용·사건 구성이 다른 두 경로
- 목표와 무관한 선택 발견 1개 이상
- 정보나 스킬로 발견할 수 있는 지름길 후보 1개 이상
- 목표 뒤 `즉시 귀환`과 `미방문 방 계속 탐색`
- 선택 때문에 열린 길 1개와 닫히거나 비싸진 길 최대 1개

닫힌 길 때문에 필수 장면·경제 보상을 영구 놓치게 하지 않는다. 한 run에서 못 본 장면은
다른 template 또는 자유 탐험에서 다시 만날 수 있다.

### 7.3 도움의 단계

| 정체 시간 | 제공하는 도움 | 페널티 |
|---:|---|---|
| 30초 | 현재 가능한 행동 수와 안전 선택 위치를 은은하게 강조 | 없음 |
| 60초 | `길을 같이 볼까요?` 버튼 노출 | 없음 |
| 90초 | 목표 방향·방문한 무료 귀환 경로를 문장으로 설명 | 없음 |
| 120초 | 목록 지도로 전환 제안과 `저장하고 쉬기` 제공 | 없음 |

도움은 자동으로 선택하거나 자원을 소비하지 않는다. 도움을 썼다는 사실을 결과·보상·
분석 점수에 남기지 않는다.

## 8. 파티의 모든 캐릭터가 살아 있는 조건

### 8.1 활약 기회 계약

파티에 넣었다는 사실만으로 초상화를 보여 주는 것은 활약이 아니다. 지도 생성은 실제
소유 캐릭터마다 다음 `spotlight_offer`를 최소 하나 배치한다.

- 그 캐릭터의 고유 스킬, 성장형 스킬, 장착 트리 노드, 상위 두 능력치 중 하나를 쓸 수 있음
- 필수 경로가 아닌 선택지이므로 사용하지 않아도 완주 가능
- 사용하면 경로·정보·자원·서사 중 하나가 실제로 달라짐
- 같은 run에서 다른 캐릭터의 spotlight와 동일한 사건·동일한 선택을 공유하지 않음
- 길잡이는 완주 안전망이지만 spotlight 대상과 관계 기록 대상은 아님

세 명 파티의 일반 run은 `3명 각각 1회 + 사용자가 자유롭게 고르는 1회`의 행동자 기회를
목표로 한다. 사용자가 특정 캐릭터만 계속 선택하는 것은 허용하되, 다른 캐릭터에게 가능한
기회가 없었던 run은 콘텐츠 결함으로 기록한다.

### 8.2 출발·행동·귀환의 존재감

각 소유 파티원은 한 판에서 반드시 다음 세 층에 등장한다.

1. 출발: 목적지 또는 동행자에 대한 1개의 짧은 반응
2. 탐험: spotlight 또는 사용자가 고른 일반 행동의 고유 동작·표정
3. 귀환: 실제 행동 기록을 참조한 1개의 문장 또는 비언어 반응

행동하지 않은 캐릭터의 귀환 대사는 `내가 해결했어`처럼 사실을 위조하지 않는다.
`옆에서 지도 모서리를 붙잡고 있었어`처럼 지원·관찰 역할을 말한다.

### 8.3 파티 관계 콘텐츠

10품종은 같은 품종 조합을 포함해 `10×11÷2=55`개 관계 조합을 가진다. 출시 pack은 각
조합에 다음 3개의 짧은 관계 beat를 제공해 최소 165개를 갖는다.

| beat | 발동 | 역할 |
|---|---|---|
| `departure` | 해당 조합 첫 3회 중 미관람 1회 | 서로의 탐험 습관을 드러냄 |
| `camp` | 둘 다 한 번 이상 행동했고 쉼터 방문 | 앞선 선택을 구체적으로 되짚음 |
| `return` | 둘 중 하나가 spotlight 해결 또는 보호 | 함께한 결과를 다음 기억으로 남김 |

성장형 6종은 문장 전체를 6배로 늘리지 않고 `tone_variant`로 어미·표정·침묵 길이·시선
방향을 바꾼다. 같은 관계 beat는 최근 10회 안에 반복하지 않고, 후보가 없으면 억지 대사
대신 짧은 비언어 동작을 사용한다.

### 8.4 애착 캐릭터와 새 캐릭터의 공존

- 오래 키운 캐릭터는 개인 기록·관계 대사·친숙도 장면이 풍부해진다.
- 새 캐릭터는 공명으로 즉시 참가하고 첫 방문 반응·첫 조합 대사를 더 자주 제안받는다.
- 추천 정렬은 `최근 spotlight가 적음`, `미관람 관계 beat 있음`, `새 해결법 제공`을 이유와
  함께 표시한다.
- 사용자가 애착 캐릭터를 계속 선택하면 경고하거나 보상을 깎지 않는다.
- 장거리 개척의 구간 분담은 한 모험 안의 서사적 역할 배분이지 일일 출전 제한이 아니다.

### 8.5 감정 성장형이 눈에 보이는 방식

같은 품종의 같은 선택도 성장형에 따라 결과 수치가 아니라 표현 리듬이 달라진다.

| 성장형 | 플레이 중 읽히는 차이 |
|---|---|
| `sunny` | 먼저 다가가고 다른 파티원을 바라보며 결과를 함께 확인 |
| `rainy` | 주변 소리를 듣는 pause 뒤 작은 단서를 오래 응시 |
| `ember` | 동작 시작이 빠르고 막힌 대상 앞에서 자세를 크게 잡음 |
| `moonlit` | 먼저 거리를 두고 살핀 뒤 짧고 정확하게 행동 |
| `sparkling` | 예상 밖 방향을 바라보고 발견 순간의 표정 변화가 큼 |
| `mosaic` | 두 단서나 두 파티원을 번갈아 보고 연결 동작으로 마무리 |

모든 성장형은 한 run에 최소 한 번 표정·동작·tone_variant가 함께 드러나는 반응을 가진다.
성장형을 정신 질환·선악·성공 가능성으로 묘사하거나 특정 표현만 성적으로 우월하게 만들지
않는다.

### 8.6 스킬트리는 선택을 늘리고 공부를 강요하지 않는다

- stage 3 최초 진입에는 현재 품종의 1단 3개만 `더 멀리 보기`, `손실 막기`, `동료에게
  넘기기`처럼 플레이 문장으로 비교한다.
- 잠긴 2·3단은 효과 전문 대신 다음 성장에서 바뀌는 행동 한 줄만 보여 준다.
- 저장 전 다음 지역 예시 상황 1개를 정적 미리보기로 재생한다.
- run 중에는 유효한 문맥에서만 칩을 보여 주고 사용할 수 없는 노드 목록을 계속 띄우지
  않는다.
- 결과 화면은 `이 노드 덕분에 열린 길`을 한 번 설명하지만 더 좋은 빌드를 평가하지 않는다.
- 무료 재배분은 `실수 수정`이 아니라 `다음에는 다른 습관으로`라고 표현한다.

## 9. 사건 모음이 아니라 한 편의 모험이 되는 구조

### 9.1 지역 서사 실마리 `run_thread`

무작위 사건만 섞으면 지도는 달라도 이야기는 파편처럼 느껴진다. 모든 일반 run은 지역의
`run_thread` 하나를 뽑아 3개의 beat로 전개한다.

| beat | 배치 | 기능 |
|---|---|---|
| `seed` | 첫 2개 사건 안 | 오늘 무엇을 추적하는지 질문을 만듦 |
| `echo` | 중간 분기 한쪽 | 앞선 단서가 다른 의미일 수 있음을 보여 줌 |
| `payoff` | 목표 또는 선택 발견 | 사용자의 경로·행동자에 따른 결론과 다음 흔적 |

출시 시 지역당 3개, 총 12개의 thread를 완성한다. thread 하나는 `seed 2변형 × echo
2변형 × payoff 3변형`의 검수된 조합을 가지며, 사용자가 보지 않은 선택 결과를 이미
겪은 것처럼 쓰지 않는다. 일반 사건 40개는 thread 사이의 호흡과 지역 장치를 담당한다.

### 9.2 선택 기억

run은 다음 의미 상태를 최대 3개만 저장한다.

```text
approach: careful | bold | relational | mixed
kept_promise: true | false | unknown
discovery_focus: place | creature | object | none
```

이 값은 플레이 행동으로만 계산하고 일기 감정을 입력으로 쓰지 않는다. payoff·귀환 대사·
홈의 다음 한 줄 반응이 이 값을 참조한다. 사용자는 결과 화면에서 `조심스럽게 흔적을
따라가 약속을 지켰어요`처럼 어떤 선택이 어떤 기억을 만들었는지 확인한다.

### 9.3 홈으로 돌아온 뒤의 여운

- 귀환 뒤 첫 홈 진입에서 선두 캐릭터가 최근 run의 장소·상대·선택 중 하나를 1문장으로
  언급한다.
- 다른 파티원은 24시간 안에 한 번씩 작은 비언어 반응 또는 보조 문장을 보여 준다.
- 같은 회상은 한 번만 자동 재생하고 이후에는 개인 기록에서 다시 본다.
- 새 도감·연구·의상 재료는 어느 탐험의 누구와 찾았는지 provenance를 유지한다.
- 다음 탐험 카드에는 보상 카운트다운이 아니라 미완성 thread 또는 미관람 관계를 최대
  하나만 제안한다.

## 10. 긴장감은 손실 공포가 아니라 판단에서 만든다

### 10.1 세 난이도의 경험 차이

| 난이도 | 대상 | 정보와 구조 | 경제 보상 |
|---|---|---|---|
| 편안한 이야기 | 서사·캐릭터 중심 | 비용 전부 공개, 안전 비용 0, 지도 장치 1단 | 동일 |
| 표준 탐험 | 기본 경험 | 비용·결과 공개, 안전 비용 0~1, 장치 1~2단 | 동일 |
| 깊은 조사 | 퍼즐·경로 중심 | 선택 도전·연쇄 상태 추가, 힌트는 요청 시 제공 | 동일 |

난이도는 출발 전과 run 밖에서 무료 변경한다. `편안한 이야기는 진짜 모드가 아니다`,
`깊은 조사가 정답이다`라는 표현·배지를 사용하지 않는다. 최초 꾸미기 보상도 세 난이도
중 아무거나 완주하면 열리고, 깊은 조사의 기록 테두리는 난이도 선택의 표시일 뿐 우월
등급으로 정렬하지 않는다.

### 10.2 자원 긴장 곡선

- 첫 두 사건은 준비도 손실 예상이 최대 1이며 안전 선택 비용 0을 하나 포함한다.
- run 중간에는 길빛과 선택 발견 사이에서 한 번 고민하게 한다.
- 목표 필수 경로에 들어설 때는 어떤 합법 파티도 길빛 2, 준비도 1 이상의 여유를 갖는다.
- 준비도 1이면 위험 선택을 빨간색으로 겁주지 않고 `이 선택 뒤에는 안전 귀환할 수
  있어요`를 명시한다.
- 자원 0은 캐릭터의 무능이 아니라 오늘 탐험을 충분히 했다는 서사로 표현한다.

### 10.3 좌절 복구 사다리

| 상황 | 즉시 복구 | 다음 run 개선 |
|---|---|---|
| 길빛 부족 | 방문 경로 무료 귀환·빠른 귀환 | 출발 화면에 최근 소비 패턴과 길 읽기 도구 제안 |
| 준비도 0 | 발견 보존 안전 귀환 | 30일 안에는 같은 thread의 미관람 payoff를 새 지도로 이어 볼 수 있음 |
| 스킬을 너무 일찍 사용 | 안전 경로와 일반 선택 유지 | 결과에서 다른 사용 지점을 정답처럼 훈계하지 않음 |
| 앱/네트워크 종료 | 마지막 확정 행동 복구 | 중복 입력·보상 없음 |
| 어려운 문장 | 쉬운 문장 보기·읽어주기 | 설정을 계정에 유지 |
| 모션 불편 | 즉시 움직임 줄이기 | 다음 화면부터 정적 전환 |

## 11. 보상이 플레이의 의미를 가리지 않는 순서

### 11.1 결과 공개 25초 계약

기본 결과 연출은 25초 안에 끝나고 처음부터 `건너뛰기`가 가능하다. 건너뛰어도 모든
기록과 보상은 이미 서버에서 확정돼 있다.

| 시간 | 화면 | 건너뛰기 뒤 남는 것 |
|---:|---|---|
| 0~4초 | 참여 캐릭터가 함께 돌아오는 한 동작 | 정적 원정 사진 |
| 4~10초 | 가장 의미 있던 선택과 행동자 | 해결 기록 카드 |
| 10~16초 | thread payoff·새 발견 | 도감 바로가기 |
| 16~21초 | 유대·관계 변화 | 누구와 무엇이 열렸는지 |
| 21~25초 | XP·씨앗·재료 | 정확한 수량과 provenance |

보상 상자 여러 개를 연속 탭하게 하지 않는다. 새 항목은 한 화면에 모으고 `모두 확인`을
제공한다.

### 11.2 자유 탐험도 헛되지 않게

자유 탐험에는 경제 보상이 없지만 다음 중 하나가 남을 수 있다.

- 미관람 thread beat 또는 발견 장면
- 캐릭터별 하루 1점의 유대·지역 친숙도
- 미관람 관계 beat·원정 사진 구도
- 지도 template 방문 기록과 개인 낙서

출발 전 `재화는 없지만 새로운 이야기 2개를 만날 수 있어요`처럼 실제 미관람 후보 수를
알린다. 미관람 콘텐츠가 없으면 `기록을 다시 만드는 산책`이라고 명시하며 새 콘텐츠처럼
포장하지 않는다.

### 11.3 아이템의 의미

- 경제 재료는 수치 장비 강화보다 연구·정원 꾸미기·의상 제작의 명확한 목표에 연결한다.
- 결과 카드에서 `어디서`, `누가 발견`, `무엇에 사용`을 한 번에 보여 준다.
- 제작 화면에서 부족 재료를 누르면 가능한 지역은 보여 주되 특정 사건 확률을 과장하지
  않는다.
- 희귀도 색은 획득 확률이 아니라 이야기·제작 용도를 나타내며 색상 외 아이콘·텍스트를
  같이 쓴다.

## 12. 조작감·연출·사운드 피드백

### 12.1 입력 반응 예산

| 행동 | 1차 피드백 | 완료 피드백 | 입력 재허용 |
|---|---:|---:|---:|
| 카드·방 탭 | 50ms 안에 눌림·초점 | 150ms 안에 상세 펼침 | 즉시 |
| 이동 확정 | 50ms 안에 경로 pulse | 서버 확정 뒤 350~600ms 이동 | 도착 뒤 |
| 선택 확정 | 50ms 안에 pending | 500~900ms 캐릭터 반응 뒤 결과 | 결과 카드 표시 뒤 |
| 스킬 | 50ms 안에 캐릭터 초점 | 400~700ms signature | 상태 반영 뒤 |
| 귀환 | 50ms 안에 저장 상태 | 25초 이하 결과 sequence | skip은 즉시 |

네트워크가 300ms를 넘으면 현재 버튼 안에 진행 상태를 표시하고 전체 화면 spinner로
지도를 가리지 않는다. 2초를 넘으면 `연결을 확인하고 있어요 · 진행은 저장돼요`, 8초를
넘으면 `다시 시도`와 `허브로`를 함께 제공한다.

### 12.2 캐릭터 연출 우선순위

1. 행동자 얼굴·손·몸 방향
2. 행동 결과와 상호작용 대상
3. 다른 파티원의 짧은 반응
4. 환경 effect
5. UI 보상 effect

환경 빛과 파티클이 캐릭터 얼굴을 가리거나 의상 실루엣보다 강하면 실패다. 같은 action을
연속 재생할 때는 캐릭터별 alternate timing 2종을 교대로 쓰되 게임 결과 시간은 바꾸지
않는다.

### 12.3 소리의 의미

- 이동 소리는 지역보다 캐릭터·화분 재질을 먼저 들려 동행감을 만든다.
- 사건 해결은 `flourish`와 `clear`의 음량 차이를 3dB 이내로 두고 detour를 실패음으로
  만들지 않는다.
- 숨은 길 소리는 화면을 보지 않아도 방향을 구분할 수 있게 stereo와 음높이를 함께 쓰고
  mono에서도 방향 label을 읽는다.
- 목표 발견 뒤 BGM은 1개 layer만 더하고 보상 수량에 따라 화려해지지 않는다.
- 캐릭터 signature 10종은 700ms 이하이며 대사 읽기와 겹치면 자동으로 -8dB ducking한다.

### 12.4 모션을 줄여도 손맛을 유지한다

`reduce motion`에서는 지도 pan·scale, 전체 fade, 흔들림, 반복 파티클을 없앤다. 대신
색에 의존하지 않는 테두리 변화, 아이콘 상태, 짧은 소리, 정적 pose 교체로 동일한 확정
감각을 준다. 기능 설명이나 사건 결과가 애니메이션 안에만 존재하면 안 된다.

## 13. 접근성은 별도 모드가 아니라 같은 탐험이다

### 13.1 화면과 인지

- 320px 폭·200% 글자에서도 선택의 행동, 비용, 예상 결과, 확정 버튼이 같은 화면 흐름에
  있고 가로 스크롤이 없다.
- 배경 위 본문 대비 4.5:1, 큰 글자와 핵심 아이콘 3:1을 만족한다.
- sunny/rainy/ember/moonlit/sparkling/mosaic와 node 상태는 색뿐 아니라 문양·이름을 쓴다.
- 사건 본문은 `기본 문장`과 의미가 같은 `쉬운 문장`을 제공한다. 쉬운 문장은 결과·보상·
  선택 수를 줄이지 않는다.
- 한 화면에서 새 개념은 하나, 주요 행동은 최대 4개, 펼치지 않은 상세 숫자는 최대 5개다.

### 13.2 스크린리더와 키보드

- 지도 읽기 순서는 `현재 방 → 시계 방향의 연결된 방 → 파티 → 자원 → 보조 행동`이다.
- 방 label은 `방향, 방문 상태, 방 종류, 길빛 비용, 연결 상태`를 포함한다.
- 선택 label은 `행동, 행동자, 점수/기준, 예상 결과, 비용, 스킬 소모`를 한 문장으로 읽는다.
- 지도와 목록 보기에서 가능한 이동·선택 집합과 서버 요청은 완전히 같다.
- 모든 기능은 키보드와 switch access로 완주할 수 있고 drag-only 조작이 없다.
- 포커스는 bottom sheet가 닫히면 열었던 방/선택으로 돌아간다.

### 13.3 청각·운동·감각

- 중요한 음향에는 자막 또는 시각 방향 표시가 있다.
- 촉각·음악·효과음·캐릭터 음성을 각각 끌 수 있다.
- 연속 탭, 길게 누르기, 빠른 반응, 정밀 drag를 요구하지 않는다.
- 광과민 보호를 위해 3Hz 이상 점멸 0, 화면 25% 이상을 덮는 갑작스러운 백색 flash 0이다.
- 설정 변경은 진행 run에 즉시 적용되고 다음 접속에도 유지된다.

### 13.4 정서 안전

- 위험 사건에 현실의 자해·죽음·유기·심각한 질병을 비유로 사용하지 않는다.
- 안전 지원 활성화 중에는 성취 압박·연속 기록·미완료 알림을 숨긴다.
- 준비도와 성장형을 사용자의 정신 건강 점수처럼 설명하지 않는다.
- 캐릭터가 사용자의 선택을 비난하거나 일기 작성을 협박하지 않는다.
- 알림은 사용자가 선택한 시간대에 하루 최대 1회이며 일기·탐험 미완료를 언급하지 않는다.

## 14. 30판 뒤에도 남는 반복 재미

### 14.1 반복 단계별 새로움

| 누적 완주 | 사용자가 기대할 변화 | 시스템 보장 |
|---:|---|---|
| 1~3판 | 지도와 기본 캐릭터 행동 학습 | 서로 다른 template 우선, 같은 thread 반복 금지 |
| 4~10판 | 파티 조합·숨은 길·지역 지식 발견 | 미관람 관계 beat·thread payoff 우선 |
| 11~20판 | 트리 빌드와 새 캐릭터의 해결 방식 실험 | spotlight target과 장치 조합 중복 완화 |
| 21~30판 | 개인 기록·친숙도·장거리 조합 완성 | 미완성 개인 기록과 template mastery 표시 |
| 31판 이후 | 좋아하는 조로 산책하거나 새 pack 기다림 | 새 콘텐츠인 척하지 않는 revisit 표시 |

### 14.2 한 판의 새로움 예산

미관람 콘텐츠가 남아 있다면 일반 run은 다음 중 최소 2개를 포함한다.

- 미관람 `run_thread` beat 1개
- 미관람 일반/발견 사건 1개
- 미관람 파티 관계 beat 1개
- 아직 사용하지 않은 template 또는 숨은 연결
- 해당 캐릭터의 미관람 지역 친숙도 반응

두 개를 만들 수 없는 경우 출발 전 `이번에는 익숙한 길을 다시 걸어요`라고 알리고
자유 탐험으로만 제안한다. 보상 가능 run을 생성하기 위해 본 문구만 바꾼 복제를 새 사건으로
세지 않는다.

### 14.3 중복 방지 원장

| 항목 | 강한 회피 구간 | 완화 뒤 가중치 |
|---|---:|---:|
| topology template | 최근 2판 | 0.25 |
| run thread | 최근 3판 | 0.15 |
| 일반 사건 | 최근 2판 | 0.25 |
| 캐릭터 한 줄 대사 | 최근 5회 노출 | 0.1 |
| 관계 beat | 최근 10회 해당 조합 | 0, 후보 없으면 비언어 반응 |
| 결과 사진 구도 | 최근 3판 | 0.25 |

강한 회피는 후보가 충분할 때만 적용한다. 생성 실패를 만들거나 필수 안전 선택을 제거하지
않는다. 반복이 불가피하면 시스템은 조용히 숨기지 않고 기록 화면에 `다시 만난 장면`으로
표시한다.

### 14.4 콘텐츠 소진 뒤의 정직한 구조

- 전체 발견률 100% 뒤에도 경제 보상은 동일하지만 `새 이야기` 배지를 표시하지 않는다.
- 자유 탐험 추천은 `미관람` 대신 사용자가 즐겨 쓴 파티, 짧은 경로, 사진 구도를 제안한다.
- 개인 기록과 홈 회상은 이미 본 콘텐츠를 재조합하되 최초 발견 날짜와 재방문임을 보인다.
- 새 pack은 영구 추가하며 만료·시즌 삭제·놓치면 복구 불가능한 장면을 만들지 않는다.

## 15. 콘텐츠 운영과 품질 유지

### 15.1 출시 콘텐츠의 플레이어 체감 최소치

| 콘텐츠 | 수량 | 체감 목적 |
|---|---:|---|
| 지역 | 4 | 규칙과 분위기가 명확히 다른 거리 단계 |
| topology | 13 | 경로 기억과 갈림길 변화 |
| run thread | 12, 각 3 beat·payoff 3변형 | 한 판의 서사적 응집력 |
| 일반 사건 | 40 | 지역 장치와 선택 방식 |
| 발견 사건 | 20 | 보상 없는 호기심과 세계관 |
| 수호자 | 지역당 1, 단계 변형 3 | 한 판의 긴장 정점 |
| 품종 대사 | 기존 140 + 관계 beat 165 | 캐릭터 존재감과 파티 관계 |
| 성장형 tone | 6종 × 7 태그 | 같은 사건의 정서적 표현 차이 |
| 귀환 사진 구도 | 지역당 3 + 장거리 4 | 기억의 시각적 증거 |

단순 곱으로 문장을 생성하지 않는다. `품종`, `성장형`, `사건`, `관계` 중 화면에 가장
중요한 두 층만 문장에 드러내고 나머지는 표정·타이밍·동작으로 표현한다.

### 15.2 출시 후 pack 주기

초기 반응이 합격선을 통과한 뒤에만 8~12주 간격의 영구 콘텐츠 pack을 제작한다. 한 pack의
최소 단위는 다음과 같다.

- 기존 지역 thread 4개, 지역당 1개
- 일반/발견 사건 8개
- 관계 beat 20개와 귀환 사진 구도 2개
- 기존 10품종 모두 사용할 수 있는 해결 선택
- 새 item은 기존 가치 예산 안의 꾸미기·연구 용도

일정이 부족하면 수량을 줄여 완성도 검증을 유지한다. 비어 있는 사건, 자동 생성 문장,
능력치 인플레이션으로 업데이트 크기를 부풀리지 않는다.

### 15.3 업데이트 전 사용자 예고

- 새 pack은 내용과 영구 제공 여부를 정확히 알리고 countdown을 사용하지 않는다.
- 진행 run과 과거 기록은 이전 pack으로 재생된다.
- 새로운 지도 규칙은 튜토리얼 재생이 아니라 첫 사건의 안전한 선택으로 배운다.
- 캐릭터·트리·의상의 기존 효용이 줄면 배포하지 않고 호환 선택을 먼저 추가한다.

## 16. 화면별 플레이어 언어 계약

| 상황 | 기본 문구 | 금지 문구 |
|---|---|---|
| 보상 탐험 가능 | `오늘의 마음을 품고 한 번 떠날 수 있어요` | `일일 던전 1/1`, `놓치지 마세요` |
| 자유 탐험 | `재화 없이 이야기와 기록을 찾아요` | `보상 없음`, `효율 0` |
| 새 캐릭터 공명 | `길잡이와 함께 지금 바로 갈 수 있어요` | `레벨 부족`, `버스 받기` |
| detour | `조금 돌아가지만 안전하게 이어져요` | `실패`, `능력치 부족` |
| 준비도 0 | `오늘 찾은 것을 품고 안전하게 돌아가요` | `전멸`, `도전 실패` |
| 자율 귀환 | `여기까지의 발견을 기록하고 돌아가요` | `포기`, `보상 박탈` |
| 목표 뒤 계속 | `아직 안개 속 장면 2개가 남아 있어요` | `추가 파밍` |
| 콘텐츠 소진 | `익숙한 길을 좋아하는 조와 다시 걸어요` | `새로운 모험` |
| 저장 | `여기까지 저장됐어요` | `종료하면 진행을 잃습니다` |

문구는 사용자가 얻고 잃는 것을 숨기지 않는다. 따뜻한 말투를 이유로 경제 지급 여부나
선택 결과를 모호하게 만들지 않는다.

## 17. 실제 사용자 검증 계획

### 17.1 테스트 집단

최종 beta 100명은 다음 조건을 중복 허용해 모집하되 각 행의 최소 인원을 채운다.

| 집단 | 최소 인원 | 확인할 위험 |
|---|---:|---|
| 몽그루 신규 사용자 | 30 | 세계관·재화 지식 없이 이해 가능한가 |
| 기존 일기 중심 사용자 | 25 | 탐험이 일기를 침범하지 않는가 |
| 캐릭터 수집·꾸미기 선호 | 20 | 활약·의상·기록이 충분한가 |
| 탐색·퍼즐 선호 | 20 | 선택과 지도 깊이가 충분한가 |
| 게임 비선호·짧은 이용 | 15 | 피로와 조작 부담이 낮은가 |
| 스크린리더·확대·switch·reduce motion 사용 | 각 5, 합계 15 이상 | 같은 콘텐츠를 완주할 수 있는가 |

팀원·개발 관계자·보상을 대가로 긍정 평가를 요구받은 참가자는 출시 점수에 포함하지
않는다. 테스트 보상은 플레이 결과·평가 점수와 무관한 고정 금액이다.

### 17.2 단계별 검증

| 단계 | 참가자/세션 | 검증 | 다음 단계 조건 |
|---|---|---|---|
| 개념 인터뷰 | 8명 × 45분 | 일기와 탐험 관계, 애착·손실 금지선 | 핵심 약속을 6명 이상 같은 의미로 이해 |
| 종이/클릭 prototype | 5명 × 첫 튜토리얼 | 정보 순서·용어·길 찾기 | 치명적 막힘 0, 5명 모두 자력 귀환 |
| vertical slice | 12명 × 3판 | 조작감·선택·캐릭터 활약·반복 | 아래 핵심 지표의 임시선 통과 |
| 콘텐츠 alpha | 30명 × 10판 | thread·관계·중복·난이도 | 10판 재플레이 의향과 중복 기준 통과 |
| 출시 beta | 100명 × 7일 | 첫 30분·일기 순환·일반/장거리·접근성 | 17.4 전 항목 통과 |

테스트 사이에 같은 참가자만 반복 사용하지 않는다. 학습된 사용자는 첫 경험 문제를
발견할 수 없으므로 각 단계에 신규 사용자를 절반 이상 포함한다.

### 17.3 관찰 과제

진행자가 정답을 설명하지 않고 다음 과제를 요청한다.

1. 첫 탐험을 시작해 마음에 드는 길로 귀환한다.
2. 선택 전에 무엇이 소비되고 무슨 결과가 예상되는지 설명한다.
3. 특정 캐릭터가 활약하도록 행동 하나를 고른다.
4. 일부러 목표와 다른 길을 갔다가 되돌아온다.
5. 준비도가 1인 상태에서 계속/안전 선택을 판단한다.
6. 앱을 닫고 다른 기기 또는 새 세션에서 이어 한다.
7. 보상 탐험 뒤 자유 탐험의 차이를 설명한다.
8. 새 stage 2 캐릭터를 최신 지역에 길잡이와 편성한다.
9. reduce motion 또는 목록 지도만으로 사건 하나를 해결한다.
10. 결과 화면에서 기억나는 장면과 다시 가고 싶은 이유를 말한다.

### 17.4 사용자 경험 출시 합격선

`전체`, `신규`, `일기 중심`, `접근성` 네 집단을 각각 계산한다. 전체 평균만 높고 한
집단이 배제되면 실패다.

| 지표 | 출시 합격선 | 수집 방법 |
|---|---:|---|
| 첫 튜토리얼 자력 완주 | 전체 85%, 각 핵심 집단 80% 이상 | 행동 로그+관찰 |
| 첫 판 뒤 핵심 약속 이해 | 90% 이상 | 자기 말로 설명, 2인 blind coding |
| 선택 전 비용·결과 이해 | 95% 이상 | 과제 2 정답 |
| `내 선택이 경로를 바꿨다` | 중앙값 6/7 이상 | 세션 후 설문 |
| `캐릭터 성격이 플레이에 보였다` | 중앙값 6/7 이상 | 세션 후 설문 |
| `파티원 모두 함께한 느낌` | 85% 이상 동의 | 3인 파티 완료자 |
| `보상 없어도 다른 조로 한 번 더` | 70% 이상 동의 | 자유 탐험 의향 |
| 첫 판 재미 | 중앙값 6/7, 4 이하 10% 미만 | 7점 척도 |
| 10판 뒤 재미 | 중앙값 5.5/7 이상 | alpha 반복 집단 |
| 같은 콘텐츠라는 피로 보고 | 10판 내 15% 미만 | 인터뷰+중복 원장 |
| 결과 뒤 기억한 첫 항목이 캐릭터/장면 | 75% 이상 | 비유도 회상 질문 |
| 안전 귀환의 보존 범위 이해 | 95% 이상 | 상황 과제 |
| 첫 지도 2분 이상 정체 | 5% 미만 | telemetry |
| 진행·보상 유실, 중복 지급 | 0건 | 서버 감사 |
| 접근성 보조기술 완주 | 과제 성공 100%, P0/P1 0건 | 보조기술 세션 |
| 다시 플레이 의향 | 80% 이상 5/7 이상 | 7일 종료 설문 |

자유 탐험 의향은 실제 경제 보상을 제시하지 않은 상태에서 묻는다. `씨앗을 더 주면 할
것인가` 같은 질문으로 재미를 부풀리지 않는다.

### 17.5 정성 질문

각 세션 끝에 다음 다섯 질문을 같은 순서로 묻는다.

1. 가장 기억나는 순간은 무엇인가요?
2. 그 순간은 본인이 고른 것처럼 느껴졌나요? 왜 그렇게 느꼈나요?
3. 함께 간 캐릭터 중 누가 무엇을 했는지 기억나나요?
4. 지루하거나 억지로 해야 한다고 느낀 순간은 어디였나요?
5. 보상이 없어도 다시 간다면 무엇을 다르게 해 보고 싶나요?

`재미있었나요?`만 묻지 않는다. 답변은 장면·행동·캐릭터에 연결해 코딩하며 일기 내용이나
정신 건강 상태를 수집하지 않는다.

### 17.6 결함 심각도와 수정 순서

| 등급 | 정의 | 예 | 처리 |
|---|---|---|---|
| PX0 | 진행·안전·데이터 신뢰 파괴 | 귀환 보상 오해, 저장 유실, 보조기술 막힘 | 즉시 출시 중단 |
| PX1 | 핵심 약속 파괴 | 캐릭터 활약 없음, 선택 결과가 같음, 2분 정체 | 같은 milestone 안에서 수정·재시험 |
| PX2 | 반복 재미·표현 저하 | 대사 반복, 연출 과다, 관계 반응 어색함 | beta 전 전량 종결 |
| PX3 | 취향·미세 polish | 작은 timing·여백·어휘 선호 | 기록 후 우선순위 검토 |

한 명의 PX0, 두 명 이상의 같은 PX1은 통계 평균과 무관하게 출시를 막는다. 수정 뒤에는
문제를 보고한 사용자와 신규 사용자 모두로 같은 과제를 다시 시험한다.

## 18. 사용자 기준 100점 판정표

이 표는 문서 리뷰 점수가 아니라 실제 플레이 증거를 붙이는 release scorecard다. 각
영역의 `필수 증거`가 없으면 배점을 받을 수 없고 부분점수로 출시 차단을 덮지 않는다.

| 영역 | 배점 | 100점 경험 | 필수 증거 |
|---|---:|---|---|
| 캐릭터 애착·존재감 | 20 | 모든 파티원이 출발·활약·귀환하고 기억이 홈에 남음 | 존재감 85%, 성격 체감 6/7 |
| 선택의 주도감 | 15 | 비용·결과를 이해하고 경로·행동자·기록이 실제로 달라짐 | 이해 95%, 주도감 6/7 |
| 탐험감·자유도 | 15 | 공간을 기억하고 우회·되돌아가기·선택 발견을 스스로 사용 | 경로 2개 실제 사용, 정체 5% 미만 |
| 반복 재미·서사 여운 | 15 | 10판 뒤에도 thread·관계·조합에서 새 이유가 생김 | 10판 재미 5.5/7, 피로 15% 미만 |
| 공정한 성장·보상 | 10 | 일기가 중심이고 신·구 캐릭터와 난이도 선택이 경제적으로 동등 | 경제 불변식·신구 격차 테스트 |
| 이해하기 쉬운 UX | 10 | 첫 판을 설명 없이 완주하고 실수·복귀가 두렵지 않음 | 자력 완주 85%, 약속 이해 90% |
| 연출·조작 손맛 | 5 | 입력이 즉시 반응하고 캐릭터·소리·효과가 결과를 명확히 전달 | latency budget·기기 QA |
| 접근성·정서 안전 | 5 | 보조기술과 안전 지원에서도 같은 모험을 완주 | 접근성 과제 100%, PX0/PX1 0 |
| 시간 존중·신뢰 | 5 | 중단·복귀·skip·비과금·비FOMO 약속을 지킴 | 유실·중복 0, 문구 comprehension 95% |
| **합계** | **100** | **재미·애착·주도감·신뢰가 함께 충족** | **17.4 전체 통과** |

### 18.1 점수 해석

- `100`: 모든 자동 계약과 사용자 합격선 통과, PX0/PX1 0. 출시 가능.
- `90~99`: 좋은 prototype이지만 한 핵심 약속이 검증되지 않음. 제한 beta만 가능.
- `80~89`: 기능은 이해되지만 애착·선택·반복 중 하나가 약함. 콘텐츠 확대 금지.
- `79 이하`: 탐험 기능의 존재보다 핵심 경험을 다시 설계해야 함.

배점 합계가 100이어도 필수 증거 하나가 없으면 상태는 `미검증`이다. 수치를 맞추기 위해
응답이 불편한 사용자를 제외하거나 질문 문구를 바꾸지 않는다.

## 19. 기준 플레이 시나리오

### 19.1 첫 사용자에게 남아야 하는 기억

1. 뽀또가 기억서고 쪽 빛을 발견하고 사용자가 `같이 가 볼까?`를 누른다.
2. 길잡이와 출발하지만 화면은 전투력 대신 `뽀또는 작은 흔적을 잘 살펴요`를 보여 준다.
3. 첫 갈림길에서 짧고 젖은 길과 길지만 밝은 길의 비용·사건 종류가 보인다.
4. 사용자는 젖은 길을 골라 번진 라벨 사건에서 뽀또의 돌봄 해결을 선택한다.
5. detour가 나와도 뽀또가 잎을 펼치고 준비도 1로 천천히 다른 서랍을 찾는다. 실패음은
   없고 사용자는 열린 서쪽 길을 본다.
6. 선택 발견에서 `숨을 쉬는 장부`를 보고 되돌아가도 길빛이 줄지 않는 것을 이해한다.
7. 목표를 찾은 뒤 아직 안개 방 1개와 `지금 돌아가기`가 함께 보인다. 사용자가 귀환한다.
8. 결과에서 뽀또가 먼저 돌아오고 `젖은 이름도 천천히 읽으니까 남아 있었어`라고 말한다.
9. 보상은 그 뒤에 한 번만 나타나고, 홈의 뽀또는 장부 모양 낙서를 옆에 둔다.
10. 사용자는 다음 탐험 카드의 `이번에는 밝은 길 끝을 볼 수 있어요`를 보고 다른 선택을
    상상한다. 즉시 플레이를 강요하는 알림이나 보상 countdown은 없다.

### 19.2 10번째 탐험에서도 달라야 하는 기억

1. 사용자는 처음 키운 여우비와 오늘 stage 2가 된 하루를 관측실에 편성한다.
2. 하루는 길잡이 공명으로 바로 참가하고 첫 방문 반응을 한다.
3. 여우비가 익숙한 숨은 길을 보지만, 새 thread는 그 길을 바로 쓰기보다 별빛 장치를
   고정하면 다른 payoff가 있음을 보여 준다.
4. 사용자는 하루에게 spotlight를 넘겨 현장 정리로 성장형 스킬을 회복한다.
5. 야영지에서 두 캐릭터의 미관람 관계 beat가 앞선 선택을 되짚는다.
6. 결과는 높은 수치가 아니라 `여우비가 찾은 길을 하루가 기록했다`는 공동 기억을 남긴다.
7. 자유 탐험 카드에는 재화 0과 미관람 관계 1개가 정확히 표시된다.

### 19.3 안전 귀환에서도 지켜야 하는 기억

1. 준비도 1에서 사용자는 위험 선택과 안전 선택의 결과를 모두 본다.
2. 위험 선택 뒤 준비도 0이 되고 캐릭터가 쓰러지는 대신 서로를 챙겨 입구로 돌아온다.
3. 발견한 장면과 목표 발견 기록은 남고 경제 후보는 지급되지 않는다고 한 화면에서
   설명한다.
4. `다시 도전`이 아니라 `오늘은 여기까지`, `같은 흔적을 다시 찾기`, `홈으로`를 보여 준다.
5. 홈에서는 캐릭터가 사과하거나 사용자를 탓하지 않고 발견한 장면을 이야기한다.

## 20. 플레이어 경험 완료 정의

다음 항목을 모두 만족해야 사용자 기준 100점 설계가 실제 게임에 구현됐다고 본다.

- [ ] 첫 30분 튜토리얼에서 새 개념을 한 번에 하나씩 배우고 85% 이상 자력 완주한다.
- [ ] 모든 일반 run에 실제 파티원별 spotlight 기회가 하나 이상 있다.
- [ ] 모든 파티원이 출발·행동/지원·귀환에서 사실에 맞게 등장한다.
- [ ] 55개 품종 관계 조합의 departure/camp/return beat 165개가 검수돼 있다.
- [ ] 모든 run에 seed/echo/payoff가 연결된 지역 thread가 하나 있다.
- [ ] 모든 선택이 차이 조건 네 항목 중 둘 이상을 바꾸고 비용·결과를 확정 전에 보여 준다.
- [ ] 모든 지도에 목표 경로 2개, 선택 발견, 지름길 후보, 무료 되돌아가기가 있다.
- [ ] 90초 정체 도움과 목록 지도가 보상·선택을 대신하지 않고 막힘을 해소한다.
- [ ] 목표 확보·자율 귀환·안전 귀환의 결과와 보존 범위를 95% 이상 이해한다.
- [ ] 결과 연출은 25초 이하, 처음부터 skip 가능하고 캐릭터·장면이 보상보다 먼저다.
- [ ] 자유 탐험의 실제 미관람 수를 출발 전에 정확히 표시한다.
- [ ] 10판 뒤 재미 중앙값 5.5/7 이상, 반복 피로 보고 15% 미만이다.
- [ ] 신규·기존, 애착·수집·탐색, 짧은 이용, 접근성 집단이 각각 합격선을 통과한다.
- [ ] 320px·200%·screen reader·keyboard/switch·reduce motion으로 같은 run을 완주한다.
- [ ] 입력·네트워크·연출 예산과 캐릭터 body/outfit/effect 동기화를 실제 기기에서 지킨다.
- [ ] 일기 원문·감정 점수를 이벤트·추천·난이도·보상·분석에 사용하지 않는다.
- [ ] 자유 탐험 의향을 재화 제안 없이 측정해 70% 이상을 확인한다.
- [ ] PX0/PX1이 0이고 수정 사항을 신규 사용자로 다시 검증한다.
- [ ] 18장의 100점 필수 증거가 모두 연결돼 있다.

## 21. 재미가 부족할 때의 수정 우선순위

1. 선택이 이해되지 않으면 문장·정보 순서·비용 preview를 고친다.
2. 탐험감이 약하면 template 분기·landmark·경로 상태 변화를 고친다.
3. 캐릭터가 장식처럼 느껴지면 spotlight·행동 후 반응·홈 회상을 고친다.
4. 사건이 파편처럼 느껴지면 run thread의 seed/echo/payoff 연결을 고친다.
5. 10판 전에 질리면 중복 원장·관계 beat·template 조합을 고친다.
6. 긴장감이 없으면 자원 선택과 선택 목표를 조정하되 캐릭터 손실을 넣지 않는다.
7. 계속할 이유가 없으면 개인 기록·사진·미완성 실마리를 고치되 경제 보상을 올리지 않는다.
8. 위 항목을 고친 뒤에도 합격하지 못하면 지역·사건 수를 줄이고 핵심 한 판을 다시 만든다.

마지막 수단으로 보상을 올리거나 출석·피로도·기간 한정을 추가하는 것을 금지한다. 사용자가
돌아오는 이유는 놓치기 싫어서가 아니라, 좋아하는 캐릭터와 아직 다른 길이 남아 있어서여야
한다.

## 22. 2026-08-04 레퍼런스에서 검증한 경험 원칙

상세 비교와 전체 링크는 `interactive_adventure_design.md` 부록 C를 단일 원본으로 한다.

  다음 라운드 선공개·계속/추출 선택을 참고해, 다음 구간 시간과 보존 범위를 귀환 전에
  보여 준다.

  짧은 탐험·NPC 동료·계정 공유 진입 구조를 참고하되 장비 인플레이션은 제외한다.

  도전에서 사건과 관계가 이어지는 원칙을 `run_thread`, 관계 beat, 홈 회상으로 변환한다.

  복제하지 않는다.

공통 결론은 캐릭터를 여러 명 쓰게 ‘막는’ 것이 아니라, 낮은 진입 장벽·선택 전 정보·
반복할수록 쌓이는 관계를 함께 제공해야 한다는 것이다.
