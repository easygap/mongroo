# 2026년 9월 22일 검수 기록

이번 변경은 화면의 가독성, 자연스러운 한국어, 전투의 입력과 반응을 다듬는 데 집중했다.
디자인 자료의 출처와 적용 이유는 [화면·조작 검토](../design-system/2026-09-22-interface-research.md)에 따로 정리했다.

## 화면과 문구

- 공통 화면은 흰색·차콜로 정리하고, 캐릭터와 배경 그림이 눈에 들어오도록 했다. 오류와 피해에는 상태 색을 유지했다.
- Wanted Sans 다섯 굵기를 앱에 포함했다. 서체를 받기 위한 외부 요청 없이 표시하며, 제작자와 OFL 라이선스를 함께 실었다.
- 고정 높이 때문에 잘리던 전투 버튼을 내용에 맞춰 늘어나게 바꿨다. 긴 스킬 이름과 사용 조건을 함께 보여 준다.
- 일기 화면의 번호·중복 설명·장식 카드를 줄였다. 쓰기·수정·저장 결과를 짧고 직접적인 문장으로 안내한다.
- `공유 집중력`, `자동 지휘`, `마음 지키기`, `성장결`을 `팀 기력`, `자동 전투`, `방어`, `성장 타입`으로 정리했다.
- 홈 제목에서 긴 닉네임을 반복하지 않도록 했다. 새싹 안내와 성장 알림에서 의미가 불분명한 비유를 줄였다.
- 밝은 앱 테마에서도 데스크톱 전투 영역에 어두운 바탕을 그리도록 했다. 상단의 흰 글자가 배경에 묻히던 문제를 고치고 4.5:1 이상의 글자 대비를 검사한다.

## 전투에서 고친 문제

- 공격이 닿는 순간에 피해 숫자, 적의 피격 동작, 체력 감소, 타격음을 맞췄다. 피해가 막혔을 때는 맞는 동작을 재생하지 않는다.
- 적의 체력 표시가 폭 0으로 그려지던 문제를 고쳤다. 숫자와 막대가 모두 실제 크기로 표시되는지 검증한다.
- 일반·강한·마지막 타격에 다른 짧은 정지를 주고, 동작 줄이기에서는 생략한다.
- 지역 음악의 재생 위치를 이어 받으며 240ms 동안 전환한다. 마지막 전투, 낮은 체력, 보스 단계에서 음악의 강도를 바꾼다.
- 소리 캐시의 크기를 제한하고 동시에 들어오는 같은 파일 요청을 합쳤다. 음소거·백그라운드 전환 뒤 늦게 끝난 로딩이 소리를 다시 켜지 않게 했다.
- 자동 전투 중 설정·설명·확인 창을 열면 명령을 잠시 멈춘다. 이전 타이머나 중복 클릭이 다음 행동을 잘못 실행하지 않게 했다.
- 이동 스틱의 중앙 복귀, 다른 손가락의 입력, 화면 포커스 이탈을 처리했다.
- 진행 중인 탐험을 다시 열 때 해당 지역의 지도를 불러오도록 고쳤다.
- 후반 지역을 마쳤을 때 다음 목적지 이름이 빠지던 안내를 보완했다.

## 확인 환경

- Windows, Flutter 3.44.6 / Dart 3.12.2
- Chrome의 Flutter Web 릴리스 빌드, 별도 SQLite 테스트 DB와 API, fake AI worker
- 실제 개인정보가 없는 테스트 계정 사용
- 모바일 폭 320px·390px, 데스크톱 배치, 밝은/어두운 화면
- 200% 글씨·동작 줄이기·최소 터치 영역은 위젯 테스트로 확인

| 검사 | 결과 |
| --- | --- |
| Flutter 정적 분석 | 오류·경고 없음 |

| 탐험 콘텐츠 검증 | 네 지역 모두 통과 |

| 브라우저 자동 전투 설정 창 | 3초간 열린 상태에서 행동 요청 0건, 닫은 뒤 자동 모드 변경 확인 |
| 브라우저 연속 입력·전투 종료 | 숫자키 연속 입력 두 번에 행동 요청 한 번, 승리와 탐험 종료 확인 |
| 음원 파일 측정 | 28개 검사, 가장 높은 피크 −1.3dBFS |
| GitHub CI | 여섯 작업 모두 성공. Android APK·WebAssembly·운영용 이미지 빌드 포함 |

검사 명령은 `flutter analyze --no-pub`, `flutter test --no-pub`,
`python -m pytest -q`, `python -m ruff check app tests`,
`python -m app.content.expeditions.validator`, `python -m app.export_openapi`다.
Android와 WebAssembly 빌드, MySQL 운영 계약 검사는 저장소의 GitHub Actions에서도 실행한다.
구현 커밋 `f94f021`의 [전체 실행 결과](https://github.com/easygap/mongroo/actions/runs/35696906714)를 확인할 수 있다.

## 남은 출시 확인

이 검수는 실제 iPhone·Android 기기의 발열, 배터리, 진동 세기, 이어폰·스피커의 체감 음량을 대신하지 않는다.
최종 서명 앱의 실기기 확인과 스토어 심사·배포는 별도 단계다. 자동 검사를 통과했다는 이유로 이 항목까지 완료했다고 표시하지 않는다.
